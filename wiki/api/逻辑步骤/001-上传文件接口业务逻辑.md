# 上传文件接口 - 业务逻辑步骤

## 接口信息
- **路由**: `POST /api/v1/document/upload`
- **功能**: 上传文件到指定知识库
- **认证**: 需要用户登录

---

## 业务逻辑流程

### 第一步：用户身份认证
1. 验证用户是否已登录
2. 从请求头中获取认证令牌（JWT或API Token）
3. 解析令牌获取用户信息
4. 验证用户身份有效性

**可能失败**：用户未登录或令牌无效 → 返回认证失败

---

### 第二步：请求参数验证
1. 获取请求表单数据
2. 验证必需参数 `kb_id`（知识库ID）是否存在
   - 不存在 → 返回"缺少知识库ID"错误

3. 获取上传的文件列表
   - 没有文件 → 返回"没有文件"错误

4. 验证每个文件名
   - 文件名为空 → 返回"没有选择文件"错误
   - 文件名过长（超过UTF-8编码字节数限制）→ 返回"文件名过长"错误

**可能失败**：参数缺失或不符合规范 → 返回参数错误

---

### 第三步：知识库信息获取
1. 根据 `kb_id` 从数据库查询知识库信息
2. 验证知识库是否存在

**可能失败**：知识库不存在 → 返回"找不到数据集"错误

---

### 第四步：权限检查
1. 检查当前用户是否有权限访问该知识库
2. 验证用户是否属于知识库所属的租户
3. 检查用户-租户关联关系

**可能失败**：无权限 → 返回"无权限"错误

---

### 第五步：初始化文件夹结构
1. 获取用户根文件夹（不存在则创建）
2. 初始化知识库文档目录结构
   - 创建根目录下的"知识库"文件夹
   - 为每个知识库创建对应的子文件夹
3. 获取或创建当前知识库的文件夹

---

### 第六步：文件处理（对每个文件循环执行）

#### 6.1 判断是新增还是更新
根据文档ID判断：
- **文档ID已存在** → 执行更新流程
- **文档ID不存在** → 执行新增流程

---

#### 6.2 更新流程（文档已存在）
1. **验证文档归属**
   - 确认文档属于当前知识库
   - 不属于 → 返回"文档ID冲突"错误

2. **读取并计算文件哈希**
   - 读取上传文件的内容
   - 计算文件内容的哈希值（用于变更检测）

3. **更新文件存储**
   - 用新文件内容替换存储中的旧内容

4. **更新数据库记录**
   - 更新文档的文件大小
   - 更新文档的内容哈希值

5. **添加到成功列表**
   - 如果内容有变化，添加到返回的文件列表

**可能失败**：更新过程中异常 → 记录错误信息，继续处理下一个文件

---

#### 6.3 新增流程（创建新文档）
1. **健康检查**
   - 检查文件名格式是否合法
   - 检查文件类型是否支持
   - 检查租户配额是否允许

2. **处理文件名重复**
   - 检查知识库内是否存在同名文件
   - 如果存在，自动添加序号后缀使文件名唯一

3. **识别文件类型**
   - 根据文件扩展名判断文件类型（PDF、图片、音频、视频、Office文档等）
   - 不支持的类型 → 返回"不支持的文件类型"错误

4. **确定存储位置**
   - 检查存储位置是否已存在同名文件
   - 如果存在，添加下划线后缀直到位置可用

5. **读取并处理文件内容**
   - 读取上传文件的内容
   - 如果是PDF文件，尝试修复可能损坏的文件

6. **存储文件**
   - 将文件内容保存到对象存储（MinIO/S3等）

7. **生成缩略图**（如果支持）
   - 对于PDF：提取第一页作为缩略图
   - 对于图片：生成缩放版本
   - 保存缩略图到存储

8. **确定文档解析器**
   - 根据文件类型选择合适的解析器：
     - 图片 → 图片解析器
     - 音频 → 音频解析器
     - 演示文稿（PPT）→ 演示文稿解析器
     - 邮件（MSG/EML）→ 邮件解析器
     - 其他 → 使用知识库默认解析器

9. **创建文档数据库记录**
   - 生成唯一的文档ID
   - 记录文档信息：
     - 所属知识库ID
     - 解析器类型
     - 管道ID
     - 解析器配置
     - 创建者用户ID
     - 文件类型、名称、后缀
     - 存储位置
     - 文件大小
     - 缩略图位置
     - 内容哈希值

10. **关联到知识库文件夹**
    - 在文件管理系统中创建文件记录
    - 建立文件与文档的关联关系
    - 将文件放入知识库对应的文件夹

11. **添加到成功列表**
    - 将文档信息添加到返回列表

**可能失败**：任何步骤异常 → 记录错误信息，继续处理下一个文件

---

### 第七步：返回结果
1. **成功情况**
   - 返回成功状态码
   - 返回上传成功的文档列表及其信息

2. **部分失败情况**
   - 返回成功状态码
   - 返回成功处理的文档列表
   - 返回错误信息列表

3. **全部失败情况**
   - 返回相应的错误码和错误信息

---

## 业务规则总结

### 文件名规则
- 文件名不能为空
- UTF-8编码后长度有限制
- 同一知识库内文件名重复会自动添加序号

### 文件类型规则
- 系统支持多种文件类型（PDF、图片、音频、视频、Office文档等）
- 不支持的文件类型会被拒绝
- 不同类型文件使用不同的解析策略

### 存储规则
- 文件内容存储在对象存储系统（MinIO/S3等）
- 存储路径为：`知识库ID/文件名`
- 存储位置冲突时自动添加下划线后缀

### 权限规则
- 只有知识库所属租户的用户才能上传文件
- 用户必须与知识库在同一租户下

### 更新规则
- 通过文档ID判断是更新还是新增
- 更新时会替换文件内容并更新哈希值
- 跨知识库的文档ID冲突会被拒绝

### 文件夹结构
```
用户根目录/
└── 知识库/
    └── {知识库名称}/
        └── {文件1, 文件2, ...}
```

## 输入输出

### 输入
| 参数 | 类型 | 必需 | 说明 |
|------|------|------|------|
| kb_id | string | 是 | 目标知识库ID |
| file | file[] | 是 | 上传的文件列表（支持多个） |

### 输出
| 字段 | 类型 | 说明 |
|------|------|------|
| code | number | 状态码（0=成功） |
| message | string | 提示信息 |
| data | array | 成功上传的文档列表 |

### 文档信息
| 字段 | 说明 |
|------|------|
| id | 文档唯一ID |
| kb_id | 所属知识库ID |
| name | 文件名 |
| type | 文件类型 |
| size | 文件大小（字节） |
| location | 存储位置 |
| thumbnail | 缩略图位置 |
| content_hash | 内容哈希值 |

---

## 错误处理

| 错误场景 | 返回信息 |
|----------|----------|
| 未登录 | 认证失败 |
| 缺少知识库ID | Lack of "KB ID" |
| 没有文件 | No file part! |
| 文件名为空 | No file selected! |
| 文件名过长 | File name too long! |
| 知识库不存在 | Can't find this dataset! |
| 无权限 | No authorization. |
| 文件类型不支持 | File format issue |
| 处理异常 | 具体错误信息 |

---

## 注意事项

1. **批量上传**：支持一次上传多个文件
2. **原子性**：每个文件独立处理，一个文件失败不影响其他文件
3. **幂等性**：通过文档ID支持重复上传（更新模式）
4. **配额限制**：需要检查租户的存储配额
5. **安全扫描**：上传的文件应进行安全扫描（病毒检测等）
6. **异步处理**：大文件上传可能需要考虑分片上传和断点续传
7. **缩略图生成**：对于无法生成缩略图的文件，该字段为空
8. **PDF修复**：尝试自动修复损坏的PDF文件，修复失败则使用原文件
