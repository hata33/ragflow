# 上传文件接口技术要点

## 设计关注点

上传接口看起来简单，但实际上同时踩中了三个敏感点：

- 权限
- 存储
- 元数据一致性

## 关键技术点

### 1. 参数和权限要尽早失败

越早发现 `kb_id` 缺失、无权限、文件为空，后续损耗越小。

### 2. 文件落盘和元数据写库要配套看

只保存了文件但没写元数据，或者只写了元数据但对象存储没成功，都会留下脏状态。

### 3. 上传成功不等于可检索

上传接口只负责接收与保存，后续是否能解析、分块、入库，要看解析链路。
