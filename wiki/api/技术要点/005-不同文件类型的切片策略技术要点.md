# 不同文件类型切片策略技术要点

## 设计关注点

不同格式天然结构不同，所以“一个统一切法打天下”在文档系统里通常行不通。

## 关键技术点

### 1. 解析器选择先于分块策略

如果解析器没把结构拿出来，分块阶段也无从优化。

### 2. 结构强的格式要吃结构

例如：

- PDF 看版面和页
- DOCX 看标题和段落
- Markdown 看标题和代码块
- 表格类看行列关系

### 3. 回退策略很重要

当高级解析失败时，系统最好仍然能退回到更朴素但稳定的路径。
