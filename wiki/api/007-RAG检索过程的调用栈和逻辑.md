# RAG 检索过程：调用栈和逻辑详解

> **核心文件**: `api/db/services/dialog_service.py` → `rag/nlp/search.py` → `rag/graphrag/search.py`
> **上游文档**: [006-embedding向量嵌入与insert_chunks入库详解.md](./006-embedding向量嵌入与insert_chunks入库详解.md)

---

## 概述

本文档详细分析 RAGFlow 中 **RAG 检索（Retrieval）** 过程的完整调用栈和逻辑，覆盖从 API 请求入口到向量搜索、重排序、结果返回的全部流程。

**检索在整体流程中的位置**：

```
用户提问 → API 入口 → 对话服务 → 【检索过程】→ 提示词构建 → LLM 生成 → 响应
                                     └── 本文覆盖 ──┘
```

**核心逻辑（Lines 230-269）**：

```
search() 搜索流程：

if 无问题文本：                                    :221
    └─ 直接排序查询（按位置/时间排序）

else 有问题文本：
    ├─ 构建全文查询：self.qryr.question(qst)      :236
    │   └─ 返回 matchText 查询表达式 + keywords

        ├─ 构建融合表达式：                          :249
```

### 3.4 重排序机制

#### 3.4.1 本地混合重排序：Dealer.rerank()

**文件位置**: `rag/nlp/search.py:437-493`

```python
def rerank(self, sres, query, tkweight=0.3, vtweight=0.7, cfield="content_ltks", rank_feature=None):
```

**权重放大策略（Line 481）**：

```python
tks = content_ltks + title_tks * 2 + important_kwd * 5 + question_tks * 6
```

| 字段 | 倍率 | 说明 |
|------|------|------|
| `content_ltks` | ×1 | 内容词元 |
| `title_tks` | ×2 | 标题词元 |
| `important_kwd` | ×5 | 重要关键词 |
| `question_tks` | ×6 | 问题关键词 |

**计算公式**：

```
sim = hybrid_similarity(query_vector, chunk_vectors, keywords, token_lists, tkweight, vtweight) + rank_feature
```

#### 3.4.2 模型重排序：Dealer.rerank_by_model()

**文件位置**: `rag/nlp/search.py:494-535`

```python
def rerank_by_model(self, rerank_mdl, sres, query, tkweight=0.3, vtweight=0.7, ...):
```

**计算公式（Line 534）**：

```python

```

其中 `vtsim` 由 `rerank_mdl.similarity()` 计算，使用外部 Rerank 模型（如 BGE-Reranker）计算查询与文档的精确相关性分数。

## 7. 存储引擎查询

### 7.1 dataStore.search() 调用

搜索请求最终通过 `dataStore.search()` 发送到底层存储引擎：

```python
# Elasticsearch (rag/utils/es_conn.py)
self.es.search(index=idx_name, query=constructed_query, size=limit)

# Infinity (rag/utils/infinity_conn.py)
table.search(vector=query_vector).fusion(method="weighted_sum", weights=...)
```

### 7.2 索引名称规则

```python
# rag/nlp/search.py:56
def index_name(uid): return f"ragflow_{uid}"
```

每个租户（tenant）对应一个独立的索引：`ragflow_{tenant_id}`

### 7.3 存储引擎差异

| 特性 | Elasticsearch | Infinity |
|------|--------------|----------|
| 混合搜索 | 手动融合 + rerank() | 内置归一化融合 |
| 重排序 | 必须 `rerank()` 或 `rerank_by_model()` | 直接使用搜索引擎分数 |
| 向量字段 | `q_{dim}_vec` 需要显式返回 | 自动处理 |
