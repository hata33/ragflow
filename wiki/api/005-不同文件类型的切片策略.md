- 主入口：[`../../rag/app/naive.py:794-1175`](../../rag/app/naive.py:794-1175)

**支持的文件格式**：
```
文档类: .pdf, .docx, .doc
表格类: .xlsx, .xls, .csv
文本类: .txt, .md, .html, .epub
数据类: .json, .jsonl, .ldjson
代码类: .py, .js, .java, .c, .cpp, .h, .php, .go, .ts, .sh, .cs, .kt, .sql
```


#### 方案A：TCADP Parser（推荐）
```python

tcadp_parser = TCADPParser(
```

**配置参数**：
- `table_result_type`: 表格输出格式
  - `"1"` - Markdown格式
  - `"2"` - HTML格式
  - `"3"` - JSON格式
- `markdown_image_response_type`: 图片处理方式

#### 方案B：DeepDOC（默认）
```python
# D:/Project/ragflow/rag/app/naive.py:976-982
excel_parser = ExcelParser()

if parser_config.get("html4excel"):
    # 输出HTML格式
    sections = [(_, "") for _ in excel_parser.html(binary, 12) if _]
    parser_config["chunk_token_num"] = 0
else:
    # 输出纯文本格式
    sections = [(_, "") for _ in excel_parser(binary) if _]
```

**关键点**：
- `html4excel=True`: 每行生成HTML表格（12行一组）
- `html4excel=False`: 每行生成纯文本
- `chunk_token_num=0`: 禁用后续分块（表格已经是独立行）

### Excel处理策略

| 场景 | 推荐配置 | 效果 |
|------|----------|------|
| 简单表格 | 默认配置 | 每行独立chunk |
| 复杂表格 | `html4excel=True` | HTML格式保留结构 |
| 大文件 | `TCADP Parser` | 云端解析，性能更好 |
| 需要分析 | `table_result_type="3"` | JSON格式便于处理 |
