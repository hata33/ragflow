## 描述

RAGFlow Agent 是基于可视化画布的工作流编排系统，采用插件式组件架构。核心引擎在 `agent/canvas.py` 中实现，包含 Canvas 执行引擎和 Graph 结构管理。系统支持 20+ 组件类型、动态组件加载、变量引用、流程控制和事件流推送。

## 执行流程

```mermaid
flowchart TB
    START([开始]) --> INIT[初始化阶段]
    INIT --> P1[解析 DSL 配置]
    P1 --> P2[加载所有组件]
    P2 --> P3[初始化全局变量]
    P3 --> P4[设置执行路径]
    P4 --> EXEC[执行循环]

    EXEC --> E1[批量执行组件<br/>并发控制]
    E1 --> E2[处理流式输出]
    E2 --> E3[异常处理与恢复]
    E3 --> E4[决定下一个执行节点]
    E4 --> CTRL{流程控制}

    CTRL -->|Categorize/Switch| BRANCH[条件分支]
    CTRL -->|Iteration/Loop| LOOP[循环控制]
    CTRL -->|ExitLoop| EXIT[跳出循环]
    CTRL -->|默认| NEXT[顺序执行下游]

    BRANCH --> MORE{更多节点?}
    LOOP --> MORE
    EXIT --> MORE
    NEXT --> MORE

    MORE -->|是| EXEC
    MORE -->|否| END[结束处理]
    END --> EVT1[发送完成事件]
    EVT1 --> EVT2[保存执行历史]
    EVT2 --> EVT3[清理资源]
    EVT3 --> COMPLETE([完成])
```

### 事件类型

```mermaid

    START --> NODE([node_started<br/>节点开始执行])

    MSG -->|content| CONTENT[消息内容<br/>流式输出]

    MSG -->|end_to_think| THINK_END[结束思考]

    THINK_END --> MSG
```

## 与 LangGraph 对比

| 特性 | RAGFlow Agent | LangGraph |
|------|---------------|-----------|
| 设计范式 | 基于类的组件 | 基于函数的节点 |
| 状态管理 | 全局变量 + 组件输出 | 统一 State 对象 |
| 变量引用 | 专用语法 `{@}` | 直接访问 state |
| 可视化 | 内置画布编辑器 | 需要第三方工具 |
| 流式输出 | 原生支持 | 需要手动实现 |
