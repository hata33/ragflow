## 描述

RAGFlow Agent 组件系统基于 `ComponentBase` 抽象基类实现，位于 `agent/component/` 目录。包含 20+ 组件类型，分为基础组件、控制组件和工具组件。组件通过 `component_class()` 函数动态加载，支持自动发现和热加载。

## ComponentBase 基类

```
┌─────────────────────────────────────────────────────────────────────┐
│                    ComponentBase 基类                                │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  class ComponentBase(ABC):                                          │
│                                                                     │
│      @abstractmethod                                              │
│      def _invoke(self, **kwargs):                                  │
│          """子类必须实现的执行方法"""                                │
│          pass                                                      │
│                                                                     │
│      def get_input(self):                                           │
│          """获取输入参数，解析变量引用"""                             │
│          pass                                                      │
│                                                                     │
│      def set_output(self, output):                                  │
│          """设置输出结果"""                                          │
│          pass                                                      │
│                                                                     │
│      def get_variable_value(self, var):                             │
│          """解析变量引用: sys.*, env.*, component@*"""               │
│          pass                                                      │
│                                                                     │
│      def check_if_canceled(self):                                   │
│          """检查任务是否被取消"""                                    │
│          pass                                                      │
│                                                                     │
│      def handle_exception(self, e):                                 │
│          """处理异常，支持 goto 和 default_value"""                  │
│          pass                                                      │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 动态加载机制

```
component_class("Begin")
    │
    ├── 查找 agent.component 模块
    │   └── 找到 → 返回 Begin 类
    │
    ├── 查找 agent.tools 模块
    │   └── 找到 → 返回工具类
    │
    └── 查找 rag.flow 模块
        └── 找到 → 返回流程类
```

## 组件分类详解

### 1. 基础组件

| 组件 | 文件 | 功能 |
|------|------|------|
| Begin | [`begin.py`](../agent/component/begin.py) | 工作流入口，接收用户输入 |
| Message | [`message.py`](../agent/component/message.py) | 输出消息到用户 |
| UserFillUp | [`userfillup.py`](../agent/component/userfillup.py) | 等待用户输入 |
| Answer | [`answer.py`](../agent/component/answer.py) | 从 LLM 输出提取答案 |

## 组件开发流程

```
1. 创建组件文件
   agent/component/my_component.py

2. 定义组件类
   class MyComponent(ComponentBase):
       component_name = "MyComponent"
       component_desc = "组件描述"

       def _invoke(self, **kwargs):
           # 实现逻辑
           pass

3. 自动注册
   __init__.py 自动发现并加载

4. 前端配置
   添加组件配置到组件库
```

## 组件参数配置

```json
{
  "component_id": "llm_1",
  "component_type": "LLM",
  "params": {
    "model": "gpt-4",
    "temperature": 0.7,
    "max_tokens": 2000
  },
  "inputs": {
    "query": "{begin@query}",
    "context": "{retrieval@chunks}"
  }
}
```
