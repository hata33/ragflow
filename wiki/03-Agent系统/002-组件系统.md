## 描述

RAGFlow Agent 组件系统基于 `ComponentBase` 抽象基类实现，位于 `agent/component/` 目录。包含 20+ 组件类型，分为基础组件、控制组件和工具组件。组件通过 `component_class()` 函数动态加载，支持自动发现和热加载。

## 组件系统架构

## 组件执行流程

```mermaid
sequenceDiagram
    participant Canvas as Canvas
    participant Comp as Component
    participant Param as Param
    participant Func as _invoke

    Canvas->>Comp: 调用 invoke()
    Comp->>Param: get_input()
    Param-->>Comp: 返回输入参数

    Comp->>Comp: 解析变量引用

    alt 同步执行
        Comp->>Func: _invoke(**kwargs)
        Func-->>Comp: 返回结果
    else 异步执行
        Comp->>Func: _invoke_async(**kwargs)
        Func-->>Comp: 返回结果
    end

    Comp->>Comp: set_output()
    Comp-->>Canvas: 返回输出
```
