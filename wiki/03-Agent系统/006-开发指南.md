## 描述

本指南介绍如何开发 RAGFlow Agent 组件。包括创建新组件、参数验证、测试方法和最佳实践。组件开发基于 `ComponentBase` 抽象类，需要实现 `_invoke()` 方法并遵循组件规范。

## 开发流程

```
┌─────────────────────────────────────────────────────────────────────┐
│                       组件开发流程                                   │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  1. 创建组件文件                                                    │
│     agent/component/my_component.py                                │
│                                                                     │
│  2. 定义组件类                                                      │
│     class MyComponent(ComponentBase):                              │
│         component_name = "MyComponent"                             │
│         component_desc = "组件描述"                                │
│                                                                     │
│  3. 实现 _invoke 方法                                               │
│     def _invoke(self, **kwargs):                                   │
│         # 实现逻辑                                                  │
│         pass                                                       │

│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 组件模板

```python
from agent.component.base import ComponentBase

class MyComponent(ComponentBase):
    """组件描述"""

    component_name = "MyComponent"
    component_desc = "组件功能描述"

    def _invoke(self, **kwargs):
        """
        执行组件逻辑

        Args:
            **kwargs: 输入参数

        Returns:
            组件输出结果
        """
        # 1. 获取输入参数
        input_data = self.get_input()

        # 2. 检查取消状态
        self.check_if_canceled()

        # 3. 执行业务逻辑
        result = self.process(input_data)

        # 4. 设置输出
        self.set_output(result)

        return result
```

## 参数验证

### 输入参数验证

```python
def _invoke(self, **kwargs):
    # 必需参数
    query = self.get_input("query")
    if not query:
        raise ValueError("query is required")

    # 可选参数
    max_results = self.get_input("max_results") or 10

    # 类型验证
    if not isinstance(max_results, int):
        raise TypeError("max_results must be an integer")
```

### 参数配置

```json
{
  "component_id": "my_component_1",
  "component_type": "MyComponent",
  "params": {
    "query": "{begin@query}",
    "max_results": 10,
    "enabled": true
  }
}
```

```python
def _invoke(self, **kwargs):
    # 引用系统变量

    # 引用组件输出
```

## 流式输出

```python
def _invoke(self, **kwargs):
    # 流式输出
    for chunk in self.stream_generate():
        # 发送流式事件
        self._send_message(chunk)
```

## 异常处理

```python
def _invoke(self, **kwargs):
    try:
        # 业务逻辑
        result = self.process()
        return result

    except ValidationError as e:
        # 验证错误
        self.handle_exception(e)

    except Exception as e:
        # 其他异常
        if self.exception_config:
            # 使用配置的异常处理
            return self.handle_exception(e)
        else:
            raise
```

### 异常配置

```json
{
  "component_id": "my_component_1",
  "exception": {
    "goto": "error_handler_component",
    "default_value": {"error": "处理失败"}
  }
}
```

## 组件测试

```python
import pytest
from agent.component.my_component import MyComponent

def test_my_component():
    # 创建组件实例
    component = MyComponent(
        component_id="test_1",
        params={
            "query": "test query"
        }
    )

    # 执行组件
    result = component._invoke()

    # 验证结果
```

## 最佳实践

### 1. 命名规范

```
- 类名: PascalCase (MyComponent)
- 文件名: snake_case (my_component.py)
- 组件名: PascalCase (MyComponent)
```

### 2. 错误处理

```python
def _invoke(self, **kwargs):
    try:
        return self.process()
    except Exception as e:
        self.logger.error(f"Component error: {e}")
        raise
```

### 3. 日志记录

```python
def _invoke(self, **kwargs):
    self.logger.info(f"Executing component: {self.component_name}")
    self.logger.debug(f"Input: {kwargs}")

    result = self.process()

    self.logger.info(f"Component completed: {self.component_name}")
    return result
```

### 4. 超时控制

```python
from agent.component.base import timeout

@timeout(600)  # 10分钟超时
def _invoke(self, **kwargs):
    return self.process()
```

### 5. 资源清理

```python
def _invoke(self, **kwargs):
    # 使用上下文管理器
    with self.get_resource() as resource:
        result = resource.process()
        return result
    # 自动清理资源
```
