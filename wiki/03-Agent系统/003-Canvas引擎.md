## 描述

Canvas 执行引擎是 RAGFlow Agent 的核心，在 `agent/canvas.py` 中实现。继承自 Graph 类，负责工作流的执行控制、流程管理、并发控制和事件推送。引擎支持流式输出、异常恢复、任务取消和执行历史记录。

## 执行流程

```
┌─────────────────────────────────────────────────────────────────────┐
│                       执行流程                                      │
└─────────────────────────────────────────────────────────────────────┘

run(dsl)
    │
    ▼
┌─────────────┐
│ 解析 DSL    │  → 加载画布配置
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 加载组件    │  → 初始化所有组件实例
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 初始化变量  │  → globals, variables, history
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 设置路径    │  → path = ["begin"]
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 执行循环    │  ┌─────────────────────────────┐
│             │  │ while path:                 │
│             │  │   批量执行组件              │
│             │  │   处理流式输出              │
│             │  │   流程控制决策              │
│             │  │   更新执行路径              │
│             │  └─────────────────────────────┘
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 完成事件    │  → workflow_finished
└─────────────┘
```

## 批量并发执行

```
┌─────────────────────────────────────────────────────────────────────┐
│                    批量并发执行                                     │
└─────────────────────────────────────────────────────────────────────┘

_run_batch(components)
    │
    ├── 收集可执行组件
    │   └── 依赖已满足的组件
    │
    ├── 创建异步任务
    │   └── asyncio.create_task()
    │
    ├── 并发控制
    │   └── Semaphore(10)
    │
    ├── 等待完成
    │   └── asyncio.gather()
    │
    └── 处理结果
        ├── 成功 → 保存输出
        └── 失败 → 异常处理
```

## 流程控制

### 1. Categorize (条件分支)

```
┌─────────────────────────────────────────────────────────────────────┐
│  组件输出 → 类别判断 → 选择分支                                     │
│                                                                     │
│  输出 "category_a" → 执行 branch_a                                  │
│  输出 "category_b" → 执行 branch_b                                  │
│  输出其他        → 执行 branch_default                              │
└─────────────────────────────────────────────────────────────────────┘
```

### 2. Switch (多路分支)

```
┌─────────────────────────────────────────────────────────────────────┐
│  条件表达式 → 匹配分支                                              │
│                                                                     │
│  case "A" → 执行 branch_a                                          │
│  case "B" → 执行 branch_b                                          │
│  default → 执行 branch_default                                      │
└─────────────────────────────────────────────────────────────────────┘
```

### 3. Iteration (列表迭代)

```
┌─────────────────────────────────────────────────────────────────────┐
│  列表输入 → 遍历元素 → 重复执行                                     │
│                                                                     │
│  [item1, item2, item3]                                             │
│      │                                                              │
│      ├── 第1次: item = item1 → 执行下游组件                         │
│      ├── 第2次: item = item2 → 执行下游组件                         │
│      └── 第3次: item = item3 → 执行下游组件                         │
└─────────────────────────────────────────────────────────────────────┘
```

### 4. Loop (条件循环)

```
┌─────────────────────────────────────────────────────────────────────┐
│  条件判断 → 循环执行                                                │
│                                                                     │
│  while 条件为真:                                                    │
│      执行循环体组件                                                 │
│      重新评估条件                                                   │
│      条件为假时退出                                                 │
└─────────────────────────────────────────────────────────────────────┘
```

## 异常处理

```
┌─────────────────────────────────────────────────────────────────────┐
│                       异常处理                                       │
└─────────────────────────────────────────────────────────────────────┘

组件执行异常
    │
    ▼
┌─────────────┐
│ 检查异常配置 │  ├── goto → 跳转到指定组件
              │  ├── default_value → 使用默认值
              │  └── 无配置 → 抛出异常
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 记录错误    │  → 日志 + 执行上下文
└─────────────┘
```
