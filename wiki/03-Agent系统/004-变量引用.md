## 描述

RAGFlow Agent 变量引用系统支持在组件间传递数据。通过专用语法引用系统变量、环境变量和组件输出。变量解析在 `ComponentBase.get_variable_value()` 中实现，支持嵌套引用和类型转换。

## 变量类型

```
┌─────────────────────────────────────────────────────────────────────┐
│                       变量引用体系                                   │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  sys.*          → 系统变量                                          │
│  ├── sys.query        → 用户查询                                    │
│  ├── sys.user_id      → 用户 ID                                     │
│  ├── sys.files        → 上传文件                                    │
│  └── sys.history      → 对话历史                                    │
│                                                                     │
│  env.*          → 环境变量                                          │
│  ├── env.api_key      → API 密钥                                   │
│  ├── env.temperature  → 温度参数                                   │
│  └── env.max_tokens   → 最大 tokens                                 │
│                                                                     │
│  component@...  → 组件输出引用                                      │
│  ├── begin@query      → Begin 组件的 query 输出                     │
│  ├── retrieval@chunks → 检索组件的文档块                            │
│  ├── llm@answer       → LLM 组件的回答                              │
│  └── categorize@category → 分类组件的类别                          │
│                                                                     │
│  globals.*      → 全局变量                                          │
│  ├── globals.user_name → 用户名称                                   │
│  └── globals.session_id → 会话 ID                                   │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 变量引用语法

### 基本语法

```
{变量类型:变量名}

示例:
{sys:query}
{env:temperature}
{begin@query}
{globals:user_name}
```

### 字符串中使用

```
"用户查询: {sys:query}, 使用模型: {env:model}"
```

### 数组/对象访问

```
{retrieval@chunks[0].content}
{llm@output.choices[0].message}
```

## 解析流程

```
┌─────────────────────────────────────────────────────────────────────┐
│                       变量解析流程                                   │
└─────────────────────────────────────────────────────────────────────┘

"{begin@query} 和 {sys:query}"
        │
        ▼
    正则匹配
        │
        ▼
    ┌───────────┴───────────┐
    │                       │
    ▼                       ▼
组件引用                系统变量
    │                       │
    ├── 找到组件             ├── 直接返回
    ├── 获取输出             └── globals[...]
    └── 返回值
```

## 变量详解

### 1. 系统变量 (sys.*)

| 变量 | 类型 | 描述 |
|------|------|------|
| sys.query | str | 用户查询内容 |
| sys.user_id | str | 当前用户 ID |
| sys.files | list | 上传的文件列表 |
| sys.history | list | 对话历史 |

### 2. 环境变量 (env.*)

| 变量 | 类型 | 描述 |
|------|------|------|
| env.api_key | str | LLM API 密钥 |
| env.model | str | 模型名称 |
| env.temperature | float | 温度参数 |
| env.max_tokens | int | 最大 tokens |
| env.top_k | int | 检索 top-k |

### 3. 组件输出 (component@*)

语法: `{component_id@output_key}`

示例:
```
{begin@query}           → Begin 组件的 query 输出
{retrieval@chunks}      → Retrieval 组件的 chunks 输出
{llm@answer}            → LLM 组件的 answer 输出
{categorize@category}   → Categorize 组件的 category 输出
```

### 4. 全局变量 (globals.*)

语法: `{globals:variable_name}`

示例:
```
{globals:user_name}
{globals:session_id}
{globals:custom_config}
```

## 使用示例

### 在组件参数中使用

```json
{
  "component_type": "LLM",
  "params": {
    "query": "{begin@query}",
    "context": "{retrieval@chunks}",
    "model": "{env:model}",
    "temperature": "{env:temperature}"
  }
}
```

### 在表达式中使用

```
"处理用户 {sys:user_id} 的查询: {begin@query}"
```

### 条件引用

```
{categorize@category == "urgent" ? llm_urgent : llm_normal}
```

## 变量作用域

```
┌─────────────────────────────────────────────────────────────────────┐
│                       变量作用域                                     │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  全局作用域 (globals.*)                                            │
│      ├── 整个工作流共享                                            │
│      ├── 可读写                                                    │
│      └── 持久化到执行历史                                          │
│                                                                     │
│  组件作用域 (component@*)                                          │
│      ├── 组件执行后可用                                            │
│      ├── 只读                                                      │
│      └── 按执行顺序依赖                                            │
│                                                                     │
│  系统作用域 (sys.*)                                                │
│      ├── 系统自动设置                                              │
│      ├── 只读                                                      │
│      └── 包含用户输入和上下文                                       │
│                                                                     │
│  环境作用域 (env.*)                                                │
│      ├── 工作流配置                                                │
│      ├── 只读                                                      │
│      └── 包含模型参数和配置                                         │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 变量类型转换

```
┌─────────────────────────────────────────────────────────────────────┐
│                       类型转换                                       │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  字符串 → "{env:temperature}"                                      │
│  整数   → {env:max_tokens}                                         │
│  浮点   → {env:temperature}                                        │
│  布尔   → {env:enabled}                                            │
│  数组   → {sys:files}                                              │
│  对象   → {llm@output}                                             │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```
