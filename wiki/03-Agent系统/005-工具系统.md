## 描述

RAGFlow Agent 工具系统提供外部能力集成，位于 `agent/component/tools/` 目录。工具作为特殊组件集成到工作流中，支持网络搜索、知识库查询、API 调用等功能。工具通过统一的组件接口调用，支持参数配置和输出解析。

## 工具系统架构

```
┌─────────────────────────────────────────────────────────────────────┐
│                        工具系统架构                                  │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  工具组件 (继承 ComponentBase)                                      │
│      │                                                              │
│      ├── 统一接口                                                   │
│      │   ├── _invoke()      - 执行工具                              │
│      │   ├── get_input()    - 获取参数                              │
│      │   └── set_output()   - 设置输出                              │
│      │                                                              │
│      └── 工具实现                                                   │
│          ├── Tavily         - 网络搜索                              │
│          ├── Wikipedia      - 维基百科                              │
│          ├── SQL            - SQL 执行                              │
│          ├── HTTP           - HTTP 请求                             │
│          ├── Code           - 代码执行                              │
│          ├── Email          - 邮件发送                              │
│          └── ...            - 更多工具                              │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 工具开发流程

```
1. 创建工具文件
   agent/component/tools/my_tool.py

2. 定义工具类
   class MyTool(ComponentBase):
       component_name = "MyTool"
       component_desc = "工具描述"

       def _invoke(self, **kwargs):
           # 获取参数
           param1 = self.get_input("param1")

           # 执行工具逻辑
           result = self.execute_tool(param1)

           # 设置输出
           self.set_output(result)
           return result

3. 自动注册
   __init__.py 自动发现并加载

4. 前端配置
   添加工具配置到组件库
```

  }

## 工具异常处理

```
工具执行异常
    │
    ├── 检查工具配置
    │   ├── retry → 重试
    │   ├── default_value → 使用默认值
    │   └── 无配置 → 抛出异常
    │
    └── 记录错误日志
```
