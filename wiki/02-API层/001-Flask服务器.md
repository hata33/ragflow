## 描述

RAGFlow 使用 Quart (异步 Flask) 作为 Web 服务器，在 `api/ragflow_server.py` 中实现。Quart 是 Flask 的异步版本，兼容 Flask API 但基于 ASGI 协议。服务器支持异步请求处理、WebSocket 连接、信号处理和优雅关闭，默认监听 9380 端口。

## 启动流程

```
main() → 环境检查 → 初始化日志 → 数据库连接 → 注册蓝图 → 注册信号 → 启动服务
```

## 核心配置

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| HOST | 0.0.0.0 | 监听地址 |
| PORT | 9380 | 监听端口 |
| DEBUG | False | 调试模式 |
| WORKERS | 1 | 工作进程数 |

## 信号处理

```
request_started → 记录请求开始 → 设置请求上下文
request_finished → 记录请求完成 → 清理资源
request_tearing_down → 关闭连接 → 释放资源
```

## 进度更新机制

```
任务执行 → 生成进度事件 → Redis 发布/订阅 → 前端 WebSocket 订阅 → 实时更新 UI
```
