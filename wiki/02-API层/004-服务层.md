## 描述

RAGFlow 服务层位于 `api/db/services/`，包含 26 个服务类，封装所有业务逻辑。每个服务类继承自 `CommonService` 基类，提供标准的 CRUD 操作和业务方法。服务层作为 API 层和数据层的中间层，负责事务管理、数据验证和业务规则执行。

## CommonService 基类

```
┌─────────────────────────────────────────────────────────────┐
│                    CommonService 基类                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  class CommonService:                                       │
│                                                             │
│      def save(cls, model)                                   │
│          → 保存或更新模型                                   │
│          → 自动处理 created_at/updated_at                   │
│                                                             │
│      def delete(cls, model)                                 │
│          → 删除模型                                         │
│          → 软删除支持                                       │
│                                                             │
│      def get(cls, id)                                       │
│          → 根据 ID 获取                                     │
│          → 抛出 404 如果不存在                              │
│                                                             │
│      def list(cls, filters, page, page_size)                │
│          → 分页查询                                         │
│          → 支持过滤和排序                                   │
│                                                             │
│      def query(cls, filters, joins)                         │
│          → 复杂查询                                         │
│          → 支持关联查询                                     │
│                                                             │
│      def begin_transaction(cls)                             │
│          → 开始事务                                         │
│                                                             │
│      def commit_transaction(cls)                            │
│          → 提交事务                                         │
│                                                             │
│      def rollback_transaction(cls)                          │
│          → 回滚事务                                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 服务层调用流程

```
┌─────────────────────────────────────────────────────────────┐
│                     服务调用流程                              │
└─────────────────────────────────────────────────────────────┘

API 请求
    │
    ▼
┌─────────────┐
│ 蓝图路由    │  → 接收请求
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 参数验证    │  → 验证输入参数
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 调用服务    │  → ServiceClass.method()
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 业务逻辑    │  → 执行业务规则
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 数据访问    │  → ORM 操作
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 返回结果    │
└─────────────┘
```

## 事务管理

```
with Service.begin_transaction():
    service1.save(model1)
    service2.save(model2)
    service3.delete(model3)
    Service.commit_transaction()
```

## 异常处理

```
try:
    service.save(model)
except ValidationError as e:
    # 参数验证失败
    pass
except NotFoundError as e:
    # 资源不存在
    pass
except BusinessError as e:
    # 业务逻辑错误
    pass
```
