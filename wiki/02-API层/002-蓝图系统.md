## 描述

RAGFlow 使用 Flask/Quart 蓝图系统组织 API 路由。在 `api/apps/__init__.py` 中实现自动发现和注册机制，支持 16 个功能蓝图和 7 个 RESTful API 模块。蓝图按功能模块划分，每个蓝图负责特定领域的路由和处理逻辑。

## 蓝图架构

```
Quart Application
    │
    ├── 自动发现机制 (discover_blueprints)
    │
    └── 蓝图注册
        ├── 功能蓝图 (16 个)
        │   ├── kb_app           - 知识库管理
        │   ├── dialog_app       - 对话管理
        │   ├── document_app     - 文档处理
        │   ├── canvas_app       - Agent 画布
        │   ├── file_app         - 文件管理
        │   ├── user_app         - 用户管理
        │   ├── auth_app         - 认证授权
        │   ├── chunk_app        - 分块管理
        │   ├── dataset_app      - 数据集管理
        │   ├── llm_app          - LLM 配置
        │   ├── system_app       - 系统配置
        │   ├── service_app      - 服务管理
        │   ├── conversation_app - 对话历史
        │   ├── task_app         - 任务管理
        │   └── tool_app         - 工具集成
        │
        └── RESTful API (7 个)
            ├── kb               - 知识库 REST API
            ├── dataset          - 数据集 REST API
            ├── document         - 文档 REST API
            ├── dialog           - 对话 REST API
            ├── chunk            - 分块 REST API
            ├── file             - 文件 REST API
            └── canvas           - 画布 REST API
```

## 自动发现机制

```
扫描 apps/ → 动态导入 → 提取蓝图 → 注册蓝图 → 扫描 restful_apis/ → 注册 REST API
```

## URL 路由规则

| 类型 | 格式 | 示例 |
|------|------|------|
| 功能蓝图 | `/api/ + 前缀 + 路径` | `/api/kb/`, `/api/dialog/` |
| RESTful API | `/api/v1/ + 资源 + /{id}/action` | `/api/v1/kb/{kb_id}/document/{doc_id}` |

## 认证中间件

```
请求 → 提取 Token → 验证 Token → 有效/无效 → 继续/返回 401
```

## 请求处理流程

```
HTTP 请求 → 路由匹配 → 中间件处理 → 参数验证 → 业务处理 → 响应构建 → 返回响应
```

## 添加新蓝图

1. 创建 `api/apps/my_app.py`
2. 定义蓝图 `bp = Blueprint('my_app', __name__)`
3. 添加路由 `@bp.route('/endpoint')`
4. 重启服务器自动注册
