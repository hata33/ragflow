# RAGFlow 技术栈

## 概述

RAGFlow 采用现代化的技术栈，支持快速开发和灵活部署。

### 数据存储

| 组件 | 技术 | 用途 |
|------|------|------|
| **关系数据库** | MySQL / PostgreSQL | 用户数据、元数据、配置 |
| **缓存** | Redis | 会话、缓存、任务队列、分布式锁 |
| **向量存储** | Elasticsearch / Infinity | 向量存储、全文检索 |
| **对象存储** | MinIO / S3 | 文件存储、解析结果 |

## 技术选型原则

```mermaid
mindmap
  root((技术选型原则))
    Python + Quart
      AI ML 生态丰富
      异步支持高并发
      开发效率高
    React + TypeScript
      组件化开发
      类型安全
      社区活跃
    MySQL + Redis + ES
      成熟的存储方案
      高可用性
      性能优异
    Docker 部署
      环境一致
      部署简单
      易于扩展
```
