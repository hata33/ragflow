# RAGFlow 项目简介

## 概述

RAGFlow 是一个基于深度文档理解的开源 RAG（Retrieval-Augmented Generation）引擎。它结合了先进的文档解析能力、强大的检索系统和灵活的 LLM 集成，为企业级知识管理和智能问答提供完整解决方案。

## 核心特性

### 1. 深度文档理解

```mermaid
mindmap
  root((文档解析能力))
    格式支持
      PDF 文本提取与布局分析
      DOCX 段落与表格解析
      Excel 表格数据提取
      HTML 网页内容清洗
      Markdown 结构化文本
      TXT 纯文本处理
    智能能力
      OCR 识别图像文字提取
      版面分析区域划分分类
      表格识别结构化数据提取
      格式保留富文本信息维护
```

### 4. 多模型支持

| 类型 | 支持模型 |
|------|----------|
| **Chat** | OpenAI GPT-4、Anthropic Claude、通义千问、文心一言、智谱 GLM |
| **Embedding** | OpenAI、BAAI bge、Jina |
| **Rerank** | Cohere、BAAI、Jina |
| **OCR** | PaddleOCR、Tesseract |

### 5. 企业级功能

- 多租户支持和数据隔离
- 细粒度权限控制 (RBAC)
- API 密钥管理
- 分布式部署能力
