# RAGFlow 目录结构

## 概述

RAGFlow 采用模块化的目录结构，各司其职，便于维护和扩展。

## 各目录职责说明

### `api/` - 后端 API 服务

```mermaid
flowchart LR
    API[api 后端 API 服务] --> APPS[apps Flask 蓝图]
    API --> DB[db 数据库层]
    API --> UTILS[utils 工具函数]

    APPS --> KB[kb_app 知识库管理]
    APPS --> DIALOG[dialog_app 对话管理]
    APPS --> DOC[document_app 文档处理]
    APPS --> CANVAS[canvas_app Agent 画布]
    APPS --> FILE[file_app 文件管理]

    DB --> MODELS[db_models ORM 模型]
    DB --> SVC[services 业务逻辑服务]
    SVC --> KB_SVC[knowledgebase_service]
    SVC --> DOC_SVC[document_service]
    SVC --> DIALOG_SVC[dialog_service]

    style API fill:#1a73e8,stroke:#0d47a1,color:#ffffff
```

| 子目录 | 职责 |
|--------|------|
| `apps/` | Flask 蓝图，定义 API 路由和端点 |
| `db/` | 数据库模型和服务层 |
| `utils/` | 工具函数和辅助类 |

| `flow/` | RAG 管道：分块、解析、预处理 |
| `nlp/` | NLP 工具：检索、分词、工具函数 |
| `graphrag/` | GraphRAG 知识图谱实现 |
| `app/` | 应用层：知识库、对话、检索 |
