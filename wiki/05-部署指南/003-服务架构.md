## 描述

RAGFlow 服务架构包含前端代理、应用服务、工作进程和基础服务。通过 Docker Compose 编排，支持高可用和水平扩展。

## 服务详解

### 1. Nginx (可选)

- **角色**: 反向代理、负载均衡
- **端口**: 80 (HTTP), 443 (HTTPS)
- **配置**: `nginx/nginx.conf`

### 2. RAGFlow Server

- **角色**: 应用服务器
- **端口**: 9380
- **镜像**: `infiniflow/ragflow:nightly`

### 3. MySQL

- **角色**: 关系数据库
- **端口**: 3306
- **镜像**: `mysql:8.0`
- **数据卷**: `mysql_data`

### 4. Redis

- **角色**: 缓存、队列
- **端口**: 6379
- **镜像**: `redis:7.2`
- **数据卷**: `redis_data`

### 5. MinIO

- **角色**: 对象存储
- **端口**: 9000 (API), 9001 (Console)
- **镜像**: `minio/minio`
- **数据卷**: `minio_data`

### 6. Elasticsearch / Infinity

- **角色**: 向量存储
- **端口**: 9200 (ES), 9001 (Infinity)
- **镜像**: `elasticsearch:8.11` 或 `infiniflow/infinity`
- **数据卷**: `es_data` / `infinity_data`

## 扩展方式

### 水平扩展

```yaml
# docker-compose.override.yml
services:
  ragflow-server:
    deploy:
      replicas: 3

  nginx:
    ports:
      - "80:80"
```

### 垂直扩展

```yaml
services:
  ragflow-server:
    deploy:
      resources:
        limits:
          cpus: '4'
          memory: 8G
```
