## 安全配置

### 1. 网络隔离

```yaml
# 创建独立网络
docker network create ragflow-frontend
docker network create ragflow-backend
```

### 2. 密钥管理

```bash
# 使用 Docker Secrets
echo "your_password" | docker secret create mysql_password -
docker secret create redis_password redis_password.txt
```

### 3. SSL/TLS

```nginx
# nginx.conf
server {
    listen 443 ssl;
    ssl_certificate /etc/nginx/certs/server.crt;
    ssl_certificate_key /etc/nginx/certs/server.key;
}
```

## 监控告警

### 1. Prometheus 指标

```yaml
services:
  prometheus:
    image: prom/prometheus
    ports:
      - "9090:9090"
```

### 2. Grafana 可视化

```yaml
services:
  grafana:
    image: grafana/grafana
    ports:
      - "3000:3000"
```

### 3. 日志收集

```yaml
services:
  ragflow-server:
    logging:
      driver: "json-file"
      options:
        max-size: "10m"
        max-file: "3"
```

## 性能优化

### 1. 资源限制

```yaml
services:
  ragflow-server:
    deploy:
      resources:
        limits:
          cpus: '4'
          memory: 8G
        reservations:
          cpus: '2'
          memory: 4G
```

### 2. 缓存优化

```bash
# Redis 配置
REDIS_MAXMEMORY=2gb
REDIS_MAXMEMORY_POLICY=allkeys-lru
```

### 3. 数据库优化

```sql
-- MySQL 优化
SET innodb_buffer_pool_size = 4G;
SET max_connections = 500;
```

## 备份策略

### 1. 数据库备份

```bash
# 定期备份
docker compose exec mysql mysqldump -u root -p ragflow > backup.sql
```

### 2. 对象存储备份

```bash
# MinIO 同步
mc mirror minio/ragflow backup/ragflow
```

## 故障恢复

### 1. 健康检查

```yaml
healthcheck:
  test: ["CMD", "curl", "-f", "http://localhost:9380/health"]
  interval: 30s
  timeout: 10s
  retries: 3
```

### 2. 自动重启

```yaml
restart: unless-stopped
```
