## 描述

RAGFlow 环境配置通过 `docker/.env` 文件管理。包含数据库连接、缓存配置、对象存储、向量存储和应用配置。

## 配置分类

### 1. 数据库配置

```bash
# MySQL
MYSQL_HOST=mysql
MYSQL_PORT=3306
MYSQL_USER=ragflow
MYSQL_PASSWORD=ragflow123
MYSQL_DATABASE=ragflow
```

### 2. 缓存配置

```bash
# Redis
REDIS_HOST=redis
REDIS_PORT=6379
REDIS_PASSWORD=redis123
```

### 3. 对象存储配置

```bash
# MinIO
MINIO_HOST=minio
MINIO_PORT=9000
MINIO_ROOT_USER=minioadmin
MINIO_ROOT_PASSWORD=minioadmin123
MINIO_BUCKET=ragflow
```

### 4. 向量存储配置

```bash
# Elasticsearch
ES_HOST=elasticsearch
ES_PORT=9200
ES_USER=elastic
ES_PASSWORD=elastic123

# 或 Infinity
DOC_ENGINE=infinity
INFINITY_HOST=infinity
INFINITY_PORT=9001
```

### 5. 应用配置

```bash
# RAGFlow
RAGFLOW_PORT=9380
RAGFLOW_VERSION=nightly
RAGFLOW_API_KEY=your_api_key_here

# 日志
LOG_LEVEL=INFO
```

## 配置文件结构

```
docker/
├── .env                           # 环境变量
├── docker-compose.yml             # 服务编排
├── docker-compose-base.yml        # 基础服务
└── service_conf.yaml.template     # 服务配置
```

## 敏感信息处理

```bash
# 使用 secrets 管理敏感信息
docker secret create mysql_password mysql_password.txt
docker secret create redis_password redis_password.txt
```

## 配置验证

```bash
# 验证配置
docker compose config

# 检查服务状态
docker compose ps

# 测试连接
docker compose exec ragflow-server curl http://mysql:3306
```
