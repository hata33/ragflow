## 描述

RAGFlow 的数据流涵盖文档处理、知识检索、Agent 执行和对话交互四大核心场景。文档从上传到索引经历解析、分块、向量化阶段；检索流程包含查询处理、向量检索、重排序；Agent 执行基于画布定义进行组件编排和数据流转；对话流程维护上下文状态并流式返回结果。

## RAG 检索数据流

```mermaid
flowchart TB
    START([用户查询])
    START --> PRE[查询预处理<br/>接收查询<br/>查询重写<br/>意图识别]
    PRE --> KB[知识库检索<br/>获取知识库配置<br/>选择检索策略]
    KB --> VEC[向量检索<br/>向量相似度检索<br/>Elasticsearch/Infinity 查询]
    VEC --> KW[关键词检索<br/>全文检索<br/>混合检索策略]
    KW --> MERGE[结果合并<br/>合并多路检索结果]

    CTX --> LLM[LLM 生成<br/>调用 LLM<br/>流式输出]
    LLM --> RESULT[返回结果<br/>WebSocket/SSE 推送<br/>保存对话历史]
```

## Agent 执行数据流

```mermaid

    START([画布定义 DSL])
    START --> LOAD[Canvas 加载<br/>解析 DSL<br/>Graph 构建执行图]

    VAR --> EXEC[执行编排<br/>run 执行循环<br/>_run_batch 批量并发<br/>Semaphore 并发控制]
```

## 对话交互数据流

```mermaid
sequenceDiagram
    participant FE as 前端
    participant WS as WebSocket
    participant DLG as 对话管理
    participant ENG as 执行引擎
    participant LLM as LLM服务
    participant DB as 数据库

    FE->>WS: 发送消息
    WS->>WS: 连接处理<br/>验证用户会话
    WS->>DLG: 消息解析
    DLG->>DB: 加载对话<br/>获取历史上下文
    DB-->>DLG: 返回上下文
    DLG->>ENG: 执行 Agent/RAG
    ENG->>LLM: 调用 LLM
    LLM-->>ENG: 流式返回
    ENG->>WS: 流式输出<br/>SSE/WebSocket 实时更新
    WS->>FE: 逐 token 推送
    DLG->>DB: 保存对话历史<br/>更新会话状态
    FE->>WS: 关闭连接
    WS->>WS: 清理资源
```
