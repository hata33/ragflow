## 描述

RAGFlow 的数据流涵盖文档处理、知识检索、Agent 执行和对话交互四大核心场景。文档从上传到索引经历解析、分块、向量化阶段；检索流程包含查询处理、向量检索、重排序；Agent 执行基于画布定义进行组件编排和数据流转；对话流程维护上下文状态并流式返回结果。

## 文档处理数据流

```
用户上传文件
    │
    ▼
┌─────────────┐
│  文件接收   │  → 接收上传
│             │  → MinIO 存储原始文件
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  任务创建   │  → 创建解析任务
│             │  → Redis 加入任务队列
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  格式检测   │  → 检测文件类型 (PDF/DOCX/HTML...)
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  内容解析   │  → 调用对应解析器
│             │  → OCR 识别文字 (如需要)
│             │  → 版面分析和结构提取
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  文本提取   │  → 提取纯文本内容
│             │  → 保留格式信息 (标题、表格等)
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  文本分块   │  → 进行分块
│             │  → TokenChunker / TitleChunker
│             │  → 生成文档块 (chunks)
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  向量化     │  → 生成向量
│             │  → 批量处理优化
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  存储索引   │  → Elasticsearch/Infinity 存储
│             │  → 向量索引 + 元数据索引
│             │  → MySQL 更新文档状态
└─────────────┘
```

## RAG 检索数据流

```
用户查询
    │
    ▼
┌─────────────┐
│  查询预处理 │  → 接收查询
│             │  → 查询重写 (可选)
│             │  → 意图识别 (可选)
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  知识库检索 │  → 获取知识库配置
│             │  → 选择检索策略
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  向量检索   │  → 向量相似度检索
│             │  → Elasticsearch/Infinity 查询
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  关键词检索 │  → 全文检索 (可选)
│             │  → 混合检索策略
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  结果合并   │  → 合并多路检索结果
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  重排序     │  → 重排序
│             │  → 优化相关性
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  上下文组装 │  → 构建 Prompt
│             │  → 添加系统提示
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  LLM 生成   │  → 调用 LLM
│             │  → 流式输出
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  返回结果   │  → WebSocket/SSE 推送
│             │  → 保存对话历史
└─────────────┘
```

## Agent 执行数据流

```
画布定义 (DSL)
    │
    ▼
┌─────────────┐
│  Canvas 加载│  → 解析 DSL
│             │  → Graph 构建执行图
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  组件加载   │  → component_class() 动态加载
│             │  → 初始化所有组件实例
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  变量解析   │  → get_variable_value() 解析引用
│             │  → sys.*, env.*, component@*
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  执行编排   │  → run() 执行循环
│             │  → _run_batch() 批量并发
│             │  → Semaphore 并发控制
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  组件执行   │  → component._invoke()
│             │  → 具体业务逻辑
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  流程控制   │  → categorize/switch 分支
│             │  → iteration/loop 循环
│             │  → 更新执行路径
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  事件推送   │  → SSE 推送执行状态
│             │  → workflow_started → node_started → message...
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  结果输出   │  → workflow_finished
│             │  → 返回最终输出
└─────────────┘
```

## 对话交互数据流

```
前端发送消息
    │
    ▼
┌─────────────┐
│  WebSocket  │  → 接收消息
│  连接处理   │  → 验证用户会话
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  消息解析   │  → 解析消息内容
│             │  → 提取参数
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  对话管理   │  → 加载对话
│             │  → 获取历史上下文
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  Agent/ RAG │  → 执行画布 或
│  执行       │  → 执行 RAG 检索
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  流式输出   │  → 逐 token 推送
│             │  → SSE/WebSocket 实时更新
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  状态保存   │  → 保存对话历史
│             │  → 更新会话状态
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  连接关闭   │  → 清理资源
└─────────────┘
```

## 数据存储流转

```
写入流:
应用 → 服务层 → ORM (Peewee) → MySQL
                → Redis Client → Redis
                → ES Client → Elasticsearch
                → S3 Client → MinIO

读取流:
应用 → 服务层 → 缓存检查 (Redis)
                ├─ 命中 → 返回
                └─ 未命中 → 查询存储 (MySQL/ES/MinIO)
                            → 更新缓存 → 返回
```

| 路径 | 实现文件 |
|------|----------|
| MySQL (ORM) | [`api/db/db_models.py`](../api/db/db_models.py) |
| Redis (缓存) | [`api/utils/__init__.py`](../api/utils/__init__.py) |
| Elasticsearch (向量) | [`rag/nlp/search.py`](../rag/nlp/search.py) |
| MinIO (文件) | [`api/utils/file_utils.py`](../api/utils/file_utils.py) |

```
    │
    ▼
┌─────────────┐
│  事件构建   │  → event_type + data + timestamp
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  SSE 推送   │  → Server-Sent Events
│             │  → 实时推送到前端

       │
       ▼

│             │  → 显示进度
│             │  → 流式展示内容
└─────────────┘
```
