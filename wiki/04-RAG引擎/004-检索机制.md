## 描述

RAGFlow 检索引擎位于 `rag/nlp/search.py`，实现向量检索、全文检索和混合检索。支持 Elasticsearch 和 Infinity 作为向量存储，提供可配置的检索策略和重排序功能。

```
┌─────────────────────────────────────────────────────────────────────┐
│                       检索引擎架构                                   │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  Dealer (检索分发器)                                                │
│      │                                                              │
│      ├── 检索类型                                                  │
│      │   ├── 向量检索 (Vector Search)                              │
│      │   ├── 全文检索 (Full-text Search)                           │
│      │   └── 混合检索 (Hybrid Search)                              │
│      │                                                              │
│      ├── 检索策略                                                  │
│      │   ├── 相似度检索                                            │
│      │   ├── MMF 检索                                              │
│      │   └── 稠密检索                                              │
│      │                                                              │
│      └── 结果处理                                                  │
```

## 检索类型

### 1. 向量检索

```
┌─────────────────────────────────────────────────────────────────────┐
│                       向量检索流程                                   │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  查询文本                                                          │
│      │                                                              │
│      ├── 向量化                                                    │
│      │   └── embedding_model.encode()                              │
│      │                                                              │
│      ├── 相似度计算                                                │
│      │   ├── 余弦相似度                                            │
│      │   ├── 欧氏距离                                              │
│      │   └── 点积                                                  │
│      │                                                              │
│      └── Top-K 返回                                               │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 2. 全文检索

基于关键词的文本检索。

```
查询文本 → 分词 → 倒排索引查询 → BM25 排序 → Top-K 返回
```

### 3. 混合检索

结合向量和全文检索。

```
┌─────────────────────────────────────────────────────────────────────┐
│                       混合检索流程                                   │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  查询文本                                                          │
│      │                                                              │
│      ├── 向量检索 → 结果集 A                                        │
│      │                                                              │
│      ├── 全文检索 → 结果集 B                                        │
│      │                                                              │
│      └── 结果融合                                                  │
│          ├── RRF (Reciprocal Rank Fusion)                          │
│          ├── 加权融合                                              │
│          └── 去重                                                  │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 检索配置

```json
{
  "retrieval_mode": "hybrid",
  "similarity_threshold": 0.7,
  "top_k": 20,
  "rerank_enabled": true,
  "rerank_model": "bge-reranker-v2-m3",
  "filters": {
    "knowledgebase_id": "kb_001"
  }
}
```

## 检索参数

| 参数 | 默认值 | 描述 |
|------|--------|------|
| retrieval_mode | hybrid | 检索模式 (vector/keyword/hybrid) |
| similarity_threshold | 0.7 | 相似度阈值 |
| top_k | 20 | 返回结果数 |
| rerank_enabled | true | 是否重排序 |
