## 描述

RAGFlow LLM 集成层位于 `rag/llm/`，提供统一的大模型接口。支持 OpenAI、Anthropic、通义千问、文心一言、智谱 GLM 等多种模型。包含 Chat、Embedding、Rerank 三类模型接口。

## LLM 架构

```
┌─────────────────────────────────────────────────────────────────────┐
│                        LLM 架构                                     │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │

│      │                                                              │
│      ├── Chat 模型                                                 │

│      │   ├── AnthropicChat    - Anthropic Claude                   │
```

## Chat 模型

### 支持的模型

| 厂商 | 模型 |
|------|------|
| OpenAI | GPT-4, GPT-3.5-turbo |
| Anthropic | Claude 3 Opus/Sonnet/Haiku |
| 阿里云 | Qwen-Max, Qwen-Plus |
| 百度云 | ERNIE-Bot 4.0 |
| 智谱 | ChatGLM-4, ChatGLM-3 |
| 月之暗面 | Moonshot-v1-128k |

### 调用方式

```python
from rag.llm.chat_model import chat_model

# 初始化
model = chat_model("gpt-4")

# 同步调用
response = model.call(
    messages=[{"role": "user", "content": "你好"}],
    temperature=0.7
)

# 流式调用
for chunk in model.stream(messages):
    print(chunk)
```

## Embedding 模型

### 支持的模型

| 厂商 | 模型 | 维度 |
|------|------|------|
| OpenAI | text-embedding-3-small | 1536 |
| BAAI | bge-large-zh | 1024 |
| Jina | jina-embeddings-v2 | 768 |

### 调用方式

```python
from rag.llm.embedding import embedding_model

# 初始化
model = embedding_model("bge-large-zh")

# 编码
embeddings = model.encode(["文本1", "文本2"])
```

## Rerank 模型

### 支持的模型

| 厂商 | 模型 |
|------|------|
| Cohere | rerank-v3 |
| BAAI | bge-reranker-v2-m3 |
| Jina | jina-reranker-v1-base-en |

### 调用方式

```python
from rag.llm.rerank import rerank_model

# 初始化
model = rerank_model("bge-reranker-v2-m3")

# 重排序
results = model.rerank(
    query="查询文本",
    documents=["文档1", "文档2", "文档3"],
    top_n=5
)
```
