## 描述

RAGFlow 向量化引擎在 `rag/llm/embedding.py` 中实现，支持多种 Embedding 模型。向量化将文本转换为向量表示，用于语义检索。支持批量处理、多模型切换和向量缓存。

## 向量化架构

```
┌─────────────────────────────────────────────────────────────────────┐
│                       向量化引擎                                     │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  Embeddings (抽象基类)                                              │
│      │                                                              │
│      ├── 统一接口                                                   │
│      │   ├── encode()         - 编码文本                           │
│      │   ├── encode_batch()  - 批量编码                           │
│      │   └── get_dimension() - 获取向量维度                        │
│      │                                                              │
│      └── 模型实现                                                   │
│          ├── OpenAIEmbedding  - OpenAI Embedding                   │
│          ├── BAAIEmbedding   - BAAI bge                            │
│          ├── JinaEmbedding   - Jina Embeddings                     │
│          ├── LocalEmbedding  - 本地模型                            │
│          └── CustomEmbedding - 自定义模型                          │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 支持的模型

### 1. OpenAI Embedding

| 模型 | 维度 | 描述 |
|------|------|------|
| text-embedding-3-small | 1536 | 轻量级模型 |
| text-embedding-3-large | 3072 | 高质量模型 |
| text-embedding-ada-002 | 1536 | 经典模型 |

### 2. BAAI bge

| 模型 | 维度 | 描述 |
|------|------|------|
| bge-small-zh | 512 | 中文小模型 |
| bge-base-zh | 768 | 中文基础模型 |
| bge-large-zh | 1024 | 中文大模型 |

### 3. Jina Embeddings

| 模型 | 维度 | 描述 |
|------|------|------|
| jina-embeddings-v2-base-zh | 768 | 中文基础模型 |
| jina-embeddings-v2-small-en | 512 | 英文小模型 |

```
┌─────────────────────────────────────────────────────────────────────┐
│                       向量化流程                                     │

│      │                                                              │
│      ├── 预处理                                                    │

│      │   ├── 分词                                                  │

│      │   ├── 加载模型                                              │
│      │   ├── 前向计算                                              │
│      │   └── 向量输出                                              │
│      │                                                              │
│      └── 后处理                                                    │
│          ├── 归一化                                                │

```

## 批量处理

```python
# 批量向量化
texts = ["文本1", "文本2", "文本3"]
embeddings = embedding_model.encode_batch(
    texts,
    batch_size=32,
    show_progress=True
)
```

## 向量配置

```json
{
  "embedding_model": "bge-large-zh",
  "dimension": 1024,
  "normalize": true,
  "batch_size": 32,
  "cache_enabled": true
}
```
