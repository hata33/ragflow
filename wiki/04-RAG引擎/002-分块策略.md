## 描述

RAGFlow 文本分块位于 `rag/flow/chunker/` 目录，提供多种分块策略。分块是 RAG 的关键步骤，影响检索质量和生成效果。支持 Token 分块、标题分块、语义分块等策略，可配置分块大小和重叠度。

## 分块策略架构

```
┌─────────────────────────────────────────────────────────────────────┐
│                       分块策略架构                                   │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  ChunkerBase (抽象基类)                                             │
│      │                                                              │
│      ├── 统一接口                                                   │
│      │   ├── chunk()          - 执行分块                           │
│      │   ├── split()          - 文本分割                           │
│      │   └── merge()          - 合并分块                           │
│      │                                                              │
│      └── 具体策略                                                   │
│          ├── TokenChunker    - Token 分块                          │
│          ├── TitleChunker   - 标题分块                            │
│          ├── NaiveChunker   - 简单分块                            │
│          ├── SemanticChunker - 语义分块                           │
│          └── RecursiveChunker - 递归分块                          │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 分块策略详解

### 1. TokenChunker (Token 分块)

源文件: [`chunker/token_chunker.py`](../rag/flow/chunker/token_chunker.py)

基于 Token 数量的分块策略。

| 参数 | 默认值 | 描述 |
|------|--------|------|
| chunk_size | 512 | 分块大小 (Token) |
| chunk_overlap | 50 | 重叠大小 (Token) |
| tokenizer | cl100k_base | Tokenizer |

```
┌─────────────────────────────────────────────────────────────────────┐
│                      Token 分块流程                                 │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  文本输入                                                          │
│      │                                                              │
│      ├── Tokenization                                              │
│      │   └── 使用指定 tokenizer                                    │
│      │                                                              │
│      ├── 分块                                                      │
│      │   ├── 按 chunk_size 分割                                    │
│      │   ├── 添加 chunk_overlap                                    │
│      │   └── 保持语义完整                                          │
│      │                                                              │
│      └── 输出分块列表                                              │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 2. TitleChunker (标题分块)

源文件: [`chunker/title_chunker.py`](../rag/flow/chunker/title_chunker.py)

基于文档标题结构的分块策略。

| 参数 | 默认值 | 描述 |
|------|--------|------|
| max_level | 3 | 最大标题层级 |
| combine_text | true | 是否合并同标题下文本 |

```
┌─────────────────────────────────────────────────────────────────────┐
│                      标题分块流程                                   │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  文本输入                                                          │
│      │                                                              │
│      ├── 解析标题结构                                              │
│      │   ├── 识别 # 标题                                           │
│      │   ├── 确定层级                                              │
│      │   └── 构建树结构                                            │
│      │                                                              │
│      ├── 按标题分块                                                │
│      │   ├── 每个标题一个分块                                      │
│      │   ├── 包含子标题内容                                        │
│      │   └── 保留层次结构                                          │
│      │                                                              │
│      └── 输出分块列表                                              │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 3. NaiveChunker (简单分块)

源文件: [`chunker/naive_chunker.py`](../rag/flow/chunker/naive_chunker.py)

基于字符数或段落的简单分块。

| 参数 | 默认值 | 描述 |
|------|--------|------|
| chunk_size | 1000 | 分块大小 (字符) |
| separator | \n\n | 分隔符 |

### 4. SemanticChunker (语义分块)

基于语义相似度的智能分块。

| 参数 | 默认值 | 描述 |
|------|--------|------|
| threshold | 0.5 | 相似度阈值 |
| embedding_model | bge-small-zh | Embedding 模型 |

## 分块参数配置

```json
{
  "chunk_method": "token",
  "chunk_size": 512,
  "chunk_overlap": 50,
  "tokenizer": "cl100k_base"
}
```

## 分块效果对比

| 策略 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| Token 分块 | 控制精确、适合 LLM | 可能切断语义 | 通用文档 |
| 标题分块 | 保持语义完整 | 依赖标题结构 | 结构化文档 |
| 简单分块 | 快速简单 | 语义不完整 | 简单文本 |
| 语义分块 | 语义完整 | 计算开销大 | 长文档 |
