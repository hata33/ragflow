## 描述

RAGFlow 文档处理引擎位于 `deepdoc/parser/` 目录，支持多种文档格式的解析。引擎提供统一的解析器接口，支持 PDF、DOCX、Excel、HTML、Markdown、TXT 等格式。解析器结合 OCR 和版面分析技术，能够提取文本、表格、图片等复杂内容。

## 解析器架构

    class ExcelParser {

        +extract_cells()

        +preserve_format()
    }

    class HtmlParser {
        +parse()
        +clean_html()
        +extract_text()
        +remove_noise()
    }

        +parse()
        +extract_blocks()

### OCR 引擎对比

| 特性 | PaddleOCR | Tesseract |
|------|-----------|-----------|
| 多语言支持 | 优秀 | 良好 |
| 中文识别 | 优秀 | 一般 |
| 表格识别 | 支持 | 不支持 |
| 速度 | 快 | 慢 |
| 准确率 | 高 | 中 |

## 处理流程

```mermaid
sequenceDiagram
    participant File as 文件上传
    participant Detect as 格式检测
    participant Parser as 解析器
    participant OCR as OCR 引擎
    participant Layout as 版面分析
    participant Output as 输出

    File->>Detect: 上传文件
    Detect->>Detect: 检测文件类型
    Detect->>Parser: 选择对应解析器

    alt 需要 OCR
        Parser->>OCR: 图像页面
        OCR-->>Parser: 识别文本
    end

    Parser->>Layout: 版面分析
    Layout-->>Parser: 区域信息

    Parser->>Output: 结构化内容
    Output-->>File: 返回结果
```
