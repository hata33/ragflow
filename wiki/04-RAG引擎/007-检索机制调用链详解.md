## 3. 查询向量化：get_vector()

**文件位置**: `rag/nlp/search.py:111-134`

```python
async def get_vector(self, txt, emb_mdl, topk=10, similarity=0.1):
    qv, _ = await thread_pool_exec(emb_mdl.encode_queries, txt)
    embedding_data = [get_float(v) for v in qv]
    vector_column_name = f"q_{len(embedding_data)}_vec"
    return MatchDenseExpr(
        vector_column_name,    # 例: "q_1024_vec"
        embedding_data,        # 查询向量
        'float',               # 数据类型
        'cosine',              # 距离度量
        topk,                  # Top-K
        {"similarity": similarity}  # 相似度阈值
    )
```

**调用链**：
```
Dealer.get_vector()                    # search.py:111
  └─ thread_pool_exec(emb_mdl.encode_queries, txt)
       └─ LLMBundle.encode_queries()   # llm_service.py:120
            └─ self.mdl.encode_queries(query)  # 底层嵌入模型
```

**注意**: 检索使用 `encode_queries()` 而非 `encode()`，部分嵌入模型对查询和文档使用不同的编码策略。

### 5.2 内部重排序：rerank()

**文件位置**: `rag/nlp/search.py:437-492`

```python
def rerank(self, sres, query, tkweight=0.3, vtweight=0.7, ...):
    # 1. 构建查询关键词
    _, keywords = self.qryr.question(query)

    # 2. 提取每个 chunk 的向量
    ins_embd = [sres.field[id].get(vector_column, zero_vector) for id in sres.ids]

    # 3. 构建词元列表（带权重增强）
    for i in sres.ids:
        tks = (content_ltks
               + title_tks * 2         # 标题词 ×2
               + important_kwd * 5     # 重要关键词 ×5
               + question_tks * 6)     # 问题词 ×6
        ins_tw.append(tks)

    # 4. 计算混合相似度
    sim, tksim, vtsim = self.qryr.hybrid_similarity(
        sres.query_vector, ins_embd, keywords, ins_tw, tkweight, vtweight
    )

    # 5. 加上排序特征（标签 + PageRank）
    rank_fea = self._rank_feature_scores(rank_feature, sres)
    return sim + rank_fea, tksim, vtsim
```

**词元增强权重**：

| 字段 | 增强倍数 | 说明 |
|------|----------|------|
| `content_ltks` | ×1 | 内容基础词元 |
| `title_tks` | ×2 | 标题词元加权 |
| `important_kwd` | ×5 | LLM 提取的关键词加权 |
| `question_tks` | ×6 | LLM 生成的问题加权 |

### 5.3 模型重排序：rerank_by_model()

**文件位置**: `rag/nlp/search.py:494-534`

```python
def rerank_by_model(self, rerank_mdl, sres, query, tkweight=0.3, vtweight=0.7, ...):
    # 1. 构建词元列表（无增强）
    tks = content_ltks + title_tks + important_kwd

    # 2. 词元相似度
    tksim = self.qryr.token_similarity(keywords, ins_tw)

    # 3. 模型向量相似度（调用 Rerank 模型）
    vtsim, _ = rerank_mdl.similarity(query, [" ".join(tks) for tks in ins_tw])

    # 4. 加权混合 + 排序特征
    return tkweight * tksim + vtweight * vtsim + rank_fea, tksim, vtsim
```

### 5.4 混合相似度计算

**文件位置**: `rag/nlp/query.py:276-309`

```python
def hybrid_similarity(self, avec, bvecs, atks, btkss, tkweight=0.3, vtweight=0.7):
    # 向量相似度：sklearn cosine_similarity
    sims = cosine_similarity([avec], bvecs)

    # 词元相似度：Jaccard + 位置权重
    tksim = self.token_similarity(atks, btkss)

    # 向量全零时降级为纯词元
    if np.sum(sims[0]) == 0:
        return np.array(tksim), tksim, sims[0]

    # 加权混合
    return vtweight * sims[0] + tkweight * tksim, tksim, sims[0]
```

    "term_similarity": 0.73,            # 词元相似度
    "vector": [0.1, -0.2, ...],         # 嵌入向量
    "positions": [...],                 # 位置信息
    "mom_id": "",                       # 母块 ID
    "highlight": "高亮<em>内容</em>",    # 高亮文本
}
```

### 8.4 表达式类

```python
# 全文匹配表达式
MatchTextExpr(
    fields=["title_tks^10", "content_ltks^2", ...],  # 查询字段+权重
    matching_text='(RAGFlow^0.5 OR "配置 RAGFlow"~2^1.5)',  # ES 查询语法
    topn=100,
    extra_options={"minimum_should_match": 0.6}
)

# 向量匹配表达式
MatchDenseExpr(
    vector_column_name="q_1024_vec",
    embedding_data=[0.1, -0.2, ...],
    embedding_data_type="float",
    distance_type="cosine",
    topn=1024,
    extra_options={"similarity": 0.2}
)

# 融合表达式
FusionExpr(
    method="weighted_sum",
    topn=1024,
    fusion_params={"weights": "0.05,0.95"}
)
```

## 10. 关键配置参数

### 检索参数

| 参数 | 默认值 | 位置 | 说明 |
|------|--------|------|------|
| `similarity_threshold` | 0.2 | `retrieval()` | 相似度过滤阈值 |
| `vector_similarity_weight` | 0.3 | `retrieval()` | 向量相似度在重排序中的权重 |
| `top` | 1024 | `retrieval()` | 向量检索返回的最大结果数 |
| `RERANK_LIMIT` | max(30, ...) | `retrieval()` :595 | 重排序前拉取的候选数量 |
| `fusion weights` | 0.05,0.95 | `search()` :249 | 全文/向量在存储层融合的权重 |
| `min_match` | 0.6 / 0.3 | `question()` | 全文检索最小匹配比例 |

### 字段权重

| 字段 | 权重 | 作用 |
|------|------|------|
| `important_kwd` | 30 | LLM 提取的关键词 |
| `important_tks` | 20 | 重要词分词 |
| `question_tks` | 20 | LLM 生成的问题 |
| `title_tks` | 10 | 标题分词 |
| `title_sm_tks` | 5 | 标题细粒度分词 |
| `content_ltks` | 2 | 内容分词 |
