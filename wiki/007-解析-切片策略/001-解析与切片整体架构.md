# 解析与切片整体架构

## 概述

RAGFlow 的文档处理流程采用**多层适配器模式**，将不同格式的文档解析、分块、分词处理统一到一个流程中。

## 核心流程

```
原始文件 → 解析器 → sections → naive_merge → chunks → tokenize → 最终结果
```

### 流程图

```
┌─────────────────────────────────────────────────────────────────┐
│                        原始文件                                  │
│                   (PDF/DOCX/Excel/MD/TXT)                        │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                    解析器层 (Parser Layer)                       │
│                                                                  │
│  ┌──────────┬──────────┬──────────┬──────────┬──────────┐       │
│  │   PDF    │   DOCX   │  Excel   │    MD    │   TXT    │       │
│  │ Parser   │  Parser  │  Parser  │  Parser  │  Parser  │       │
│  └────┬─────┴────┬─────┴────┬─────┴────┬─────┴────┬─────┘       │
│       │          │          │          │          │              │
│       ↓          ↓          ↓          ↓          ↓              │
│  (text,tag) (text,img, (text,"") (text,"") (text,"")           │
│             |table)                                              │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│              分块路由层 (Chunking Router)                        │
│                                                                  │
│  根据文件类型和 sections 结构选择合适的 merge 函数:              │
│                                                                  │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │ if 文件类型 == DOCX:                                    │   │
│  │     → naive_merge_docx()        ← DOCX 专用            │   │
│  │ elif 有图片:                                             │   │
│  │     → naive_merge_with_images()  ← 图片处理              │   │
│  │ else:                                                     │   │
│  │     → naive_merge()                ← 纯文本              │   │
│  └─────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                    Chunks 层 (Chunk Layer)                       │
│                                                                  │
│  naive_merge()          → ["chunk1", "chunk2", ...]             │
│  naive_merge_with_images() → (["chunk1", ...], [img1, ...])      │
│  naive_merge_docx()      → [{"text":..., "ck_type":...}, ...]   │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│              Tokenize 层 (Tokenize Layer)                        │
│                                                                  │
│  tokenize_chunks()              ← 纯文本                         │
│  tokenize_chunks_with_images() ← 带图片                         │
│  doc_tokenize_chunks_with_images() ← DOCX 专用                  │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                   最终结果 (Final Result)                        │
│                                                                  │
│  [{                                                              │
│    "content_with_weight": "文本内容",                             │
│    "content_ltks": [...],           ← 粗粒度 token               │
│    "content_sm_ltks": [...],        ← 细粒度 token               │
│    "docnm_kwd": "文件名",                                       │
│    "page_num_int": [1, 2],          ← 页码列表                   │
│    "image": PIL Image / None,      ← 可选                        │
│    "doc_type_kwd": "table/image"   ← 可选                        │
│  }, ...]                                                         │
└─────────────────────────────────────────────────────────────────┘
```

## 核心文件

| 文件 | 作用 |
|------|------|
| `rag/app/naive.py` | 文档解析和分块的主入口 |
| `rag/nlp/__init__.py` | 分块和分词算法实现 |
| `deepdoc/parser/*.py` | 各格式解析器实现 |
