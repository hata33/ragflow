## 核心概念

### 检索流程

```
用户查询 → 查询构建 → 向量嵌入 → 混合检索 → 重排序 → 分页返回
```

### 三种检索路径

| 路径 | 说明 | 使用场景 |
|------|------|----------|
| 纯全文检索 | 基于 BM25 | 无嵌入模型 |
| 纯向量检索 | 基于语义相似度 | 无查询文本 |
| 混合检索 | BM25 + 向量 | 默认推荐 |

### 两种重排序策略

| 策略 | 说明 | 适用场景 |
|------|------|----------|
| 内部混合相似度 | 词元 + 向量 | 快速检索 |
| 外部 Rerank 模型 | 专用模型 | 高质量检索 |

## 常见问题

### Q: 如何选择检索引擎？

**A**:
- **Elasticsearch**: 通用检索，支持全文和向量
- **Infinity**: 专为向量检索优化，性能更高
- **OceanBase**: 结构化数据，支持全文检索

### Q: 如何调整相似度阈值？

**A**: 参考 [008-配置参数详解.md](./008-配置参数详解.md) 中的"参数调优建议"部分。

### Q: 何时使用 Rerank 模型？

**A**:
- **需要高质量结果**: 使用 Rerank 模型
- **需要快速响应**: 使用内部混合相似度
- **Infinity 引擎**: 可直接使用内置归一化分数

### Q: 如何提升检索效果？

**A**:
1. 优化查询字段权重（002-全文查询构建.md）
2. 调整融合策略权重（003-检索执行.md）
3. 使用 Rerank 模型（004-重排序机制.md）
4. 启用 TOC 检索（005-高级检索策略.md）
