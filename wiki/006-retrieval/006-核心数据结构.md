**文件位置**: `common/doc_store/doc_store_base.py:56-141`

### MatchTextExpr

全文匹配表达式，用于构建 BM25 全文检索查询。

#### 类定义

```python
class MatchTextExpr:
    def __init__(
        self,
        fields: list[str],          # 查询字段列表
        matching_text: str,         # 匹配文本（ES 查询语法）
        topn: int,                  # Top-N
        extra_options: dict | None = None  # 额外选项
    ):
        self.fields = fields
        self.matching_text = matching_text
        self.topn = topn
        self.extra_options = extra_options
```

#### 字段示例

```python
fields = [
    "title_tks^10",                   # 标题分词，权重 10
    "title_sm_tks^5",                 # 标题细粒度分词，权重 5
    "important_kwd^30",               # 重要关键词，权重 30
    "important_tks^20",               # 重要分词，权重 20
    "question_tks^20",                # 问题分词，权重 20
    "content_ltks^2",                 # 内容分词，权重 2
    "content_sm_ltks",                # 内容细粒度分词，默认权重
]
```

#### 匹配文本示例

```python
# 英文查询
matching_text = "(How^0.3 OR configure^0.5 OR RAGFlow^0.7)"

# 中文查询
matching_text = "(如何^0.5 OR 配置^0.5 OR RAGFlow^0.7 OR (RAG Flow~2)^0.35)"

# 带同义词的查询
matching_text = "(RAGFlow^0.7 OR (检索引擎~2)^0.35 OR (search engine~2)^0.2)"
```

#### 额外选项

```python
extra_options = {
    "minimum_should_match": 0.6,     # 最小匹配比例
    "original_query": "如何配置 RAGFlow",  # 原始查询
}
```

### MatchDenseExpr

向量匹配表达式，用于构建向量相似度检索查询。

#### 类定义

```python
class MatchDenseExpr:
    def __init__(
        self,
        vector_column_name: str,      # 向量列名
        embedding_data: VEC,          # 嵌入向量数据
        embedding_data_type: str,     # 数据类型
        distance_type: str,           # 距离类型
        topn: int = 10,               # Top-N
        extra_options: dict | None = None  # 额外选项
    ):
        self.vector_column_name = vector_column_name
        self.embedding_data = embedding_data
        self.embedding_data_type = embedding_data_type
        self.distance_type = distance_type
        self.topn = topn
        self.extra_options = extra_options
```

#### 向量列名规则

```python
# 格式: q_{维度}_vec
vector_column_name = f"q_{len(embedding_data)}_vec"

# 示例
# 1024 维向量: "q_1024_vec"
# 768 维向量: "q_768_vec"
```

#### 距离类型

| 类型 | 说明 | 范围 |
|------|------|------|
| `cosine` | 余弦相似度 | [-1, 1]，越大越相似 |
| `l2` | 欧氏距离 | [0, ∞)，越小越相似 |
| `dotproduct` | 点积 | (-∞, ∞)，越大越相似 |

#### 额外选项

```python
extra_options = {
    "similarity": 0.2,               # 相似度阈值
}
```

### MatchSparseExpr

稀疏向量匹配表达式，用于 BM25 等稀疏检索。

#### 类定义

```python
class MatchSparseExpr:
    def __init__(
        self,
        vector_column_name: str,      # 稀疏向量列名
        sparse_data: SparseVector | dict,  # 稀疏向量数据
        distance_type: str,           # 距离类型
        topn: int,                    # Top-N
        opt_params: dict | None = None  # 可选参数
    ):
        self.vector_column_name = vector_column_name
        self.sparse_data = sparse_data
        self.distance_type = distance_type
        self.topn = topn
        self.opt_params = opt_params
```

#### SparseVector

```python
@dataclass
class SparseVector:
    indices: list[int]                # 非零元素索引
    values: list[float] | list[int] | None = None  # 非零元素值
```

#### 示例

```python
# BM25 稀疏向量
sparse_vector = SparseVector(
    indices=[0, 5, 10, 100],
    values=[1.5, 2.3, 0.8, 3.1]
)

match_sparse = MatchSparseExpr(
    "bm25_vec",
    sparse_vector,
    "bm25",
    100
)
```

### FusionExpr

融合策略表达式，用于混合多种检索结果。

#### 类定义

```python
class FusionExpr:
    def __init__(
        self,
        method: str,                  # 融合方法
        topn: int,                    # Top-N
        fusion_params: dict | None = None  # 融合参数
    ):
        self.method = method
        self.topn = topn
        self.fusion_params = fusion_params
```

#### 融合方法

| 方法 | 说明 | 参数 |
|------|------|------|
| `weighted_sum` | 加权求和 | `weights`: "0.05,0.95" |
| `rrf` | Reciprocal Rank Fusion | `rankConstant`: 60 |
| `dfs` | Distributed Frequency Score | - |

#### weighted_sum 示例

```python
fusion = FusionExpr(
    "weighted_sum",
    1024,
    {"weights": "0.05,0.95"}  # 全文 5%，向量 95%
)
```

### OrderByExpr

排序表达式，用于指定结果排序方式。

#### 类定义

```python
class OrderByExpr:
    def __init__(self):
        self.fields = list()

    def asc(self, field: str):
        """升序排序"""
        self.fields.append((field, 0))
        return self

    def desc(self, field: str):
        """降序排序"""
        self.fields.append((field, 1))
        return self
```

#### 使用示例

```python
# 单字段排序
order_by = OrderByExpr().desc("pagerank_flt")

# 多字段排序
order_by = (OrderByExpr()
    .desc("pagerank_flt")      # 先按 PageRank 降序
    .asc("create_time_flt"))   # 再按创建时间升序
```

## SearchResult 数据类

**文件位置**: `rag/nlp/search.py:85-100`

### 类定义

```python
@dataclass
class SearchResult:
    """检索结果数据类"""

    total: int                          # 总结果数
    ids: list[str]                      # chunk ID 列表
    query_vector: list[float] = None    # 查询向量
    field: dict = None                  # {chunk_id: {field: value}}
    highlight: dict = None              # {chunk_id: highlighted_text}
    aggregation: list = None            # 聚合结果
    keywords: list = None               # 提取的关键词
    scores: list = None                 # 相似度分数（可选）
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `total` | int | 总结果数 |
| `ids` | list[str] | chunk ID 列表 |
| `query_vector` | list[float] | 查询向量（可选） |
| `field` | dict | 字典：{chunk_id: {field: value}} |
| `highlight` | dict | 高亮结果：{chunk_id: highlighted_text} |
| `aggregation` | list | 聚合结果 |
| `keywords` | list[str] | 提取的关键词 |
| `scores` | list[float] | 相似度分数（可选） |

## Chunk 字典结构

### 完整结构

```python
chunk = {
    # 基础字段
    "chunk_id": "chunk_001",           # chunk ID
    "content_ltks": "token1 token2",   # 内容分词
    "content_with_weight": "原始内容",  # 原始内容
    "content_sm_ltks": "token1 token2", # 内容细粒度分词

    # 文档信息
    "doc_id": "doc_001",               # 文档 ID
    "docnm_kwd": "report.pdf",         # 文档名
    "kb_id": "kb_001",                 # 知识库 ID

    # 增强字段
    "important_kwd": ["关键词"],         # 重要关键词
    "important_tks": ["重要", "词"],    # 重要词分词
    "question_tks": ["问题", "词"],     # 问题分词

    # 标题字段
    "title_tks": ["标题", "词"],        # 标题分词
    "title_sm_tks": ["标题", "词"],     # 标题细粒度分词

    # 相似度分数
    "similarity": 0.85,                # 综合相似度
    "vector_similarity": 0.92,         # 向量相似度
    "term_similarity": 0.73,           # 词元相似度

    # 向量数据
    "q_1024_vec": [0.1, -0.2, ...],    # 1024 维向量
    "vector": [0.1, -0.2, ...],        # 嵌入向量

    # 位置信息
    "positions": [[0, 100], [200, 300]],  # 位置信息

    # 层级结构
    "mom_id": "mom_001",               # 母块 ID
    "toc_kwd": "toc",                  # TOC 标记

    # 媒体信息
    "image_id": "img_xxx",             # 图片 ID

    # 排序特征
    "pagerank_flt": 10.5,              # PageRank 分数
    "tag_kwd": ["important"],          # 标签

    # 高亮结果
    "highlight": "高亮<em>内容</em>",  # 高亮文本
}
```

### 字段分类

#### 基础字段

| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `chunk_id` | str | 是 | chunk 唯一标识 |
| `content_ltks` | str | 是 | 内容分词（空格分隔） |
| `content_with_weight` | str | 是 | 原始内容 |
| `doc_id` | str | 是 | 所属文档 ID |
| `docnm_kwd` | str | 是 | 文档名称 |
| `kb_id` | str | 是 | 所属知识库 ID |

#### 相似度字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `similarity` | float | 综合相似度（混合重排序后） |
| `vector_similarity` | float | 向量相似度 |
| `term_similarity` | float | 词元相似度 |

#### 向量字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `q_{维度}_vec` | list[float] | 特定维度的向量（如 q_1024_vec） |
| `vector` | list[float] | 通用向量字段 |

#### 增强字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `important_kwd` | list[str] | LLM 提取的重要关键词 |
| `important_tks` | list[str] | 重要词分词 |
| `question_tks` | list[str] | LLM 生成的问题词 |
| `title_tks` | list[str] | 标题分词 |

#### 层级字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `mom_id` | str | 母块 ID（用于父子块检索） |
| `toc_kwd` | str | TOC 标记 |

#### 排序特征

| 字段 | 类型 | 说明 |
|------|------|------|
| `pagerank_flt` | float | PageRank 分数 |
| `tag_kwd` | list[str] | 标签列表 |

## 检索请求结构

### 完整结构

```python
req = {
    # 过滤条件
    "kb_ids": ["kb_001", "kb_002"],    # 知识库过滤
    "doc_ids": ["doc_001"],             # 文档过滤（可选）

    # 分页参数
    "page": 1,                          # 页码
    "size": 30,                         # 每页大小

    # 查询参数
    "question": "如何配置 RAGFlow",      # 查询文本
    "topk": 1024,                       # 向量检索 Top-K
    "similarity": 0.2,                  # 相似度阈值

    # 可用性过滤
    "available_int": 1,                 # 只检索可用的 chunk
}
```

### 字段说明

| 字段 | 类型 | 必需 | 默认值 | 说明 |
|------|------|------|--------|------|
| `kb_ids` | list[str] | 是 | - | 知识库 ID 列表 |
| `doc_ids` | list[str] | 否 | [] | 文档 ID 过滤 |
| `page` | int | 是 | - | 页码（从 1 开始） |
| `size` | int | 是 | - | 每页大小 |
| `question` | str | 是 | - | 查询文本 |
| `topk` | int | 是 | 1024 | 向量检索 Top-K |
| `similarity` | float | 否 | 0.2 | 相似度阈值 |
| `available_int` | int | 否 | 1 | 可用性过滤 |
