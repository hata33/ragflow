## 概述

检索系统的行为受多种配置参数影响。本文档详细解析这些参数的含义、默认值和影响。

## 检索参数

### retrieval() 方法参数

**文件位置**: `rag/nlp/search.py:542-566`

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `similarity_threshold` | float | 0.2 | 相似度过滤阈值，低于此值的结果被过滤 |
| `vector_similarity_weight` | float | 0.3 | 向量相似度在重排序中的权重（词元权重 = 1 - 此值） |
| `top` | int | 1024 | 向量检索返回的最大结果数 |
| `page` | int | - | 页码，从 1 开始 |
| `page_size` | int | - | 每页大小 |

### RERANK_LIMIT

**文件位置**: `rag/nlp/search.py:595`

```python
RERANK_LIMIT = int(math.ceil(64/page_size) * page_size)
RERANK_LIMIT = max(30, RERANK_LIMIT)
```

**说明**: 确保有足够的候选结果进行重排序，至少 30 条。

**计算示例**:

| page_size | RERANK_LIMIT |
|-----------|--------------|
| 10 | 70 (ceil(6.4) * 10) |
| 20 | 80 (ceil(3.2) * 20) |
| 30 | 64 (ceil(2.13) * 30) |
| 50 | 64 (ceil(1.28) * 50) |

## 混合检索参数

### 融合策略权重

**文件位置**: `rag/nlp/search.py:249`

```python
fusionExpr = FusionExpr("weighted_sum", topk, {"weights": "0.05,0.95"})
```

| 权重 | 值 | 说明 |
|------|------|------|
| 全文检索权重 | 0.05 | BM25 分数权重 |
| 向量检索权重 | 0.95 | 余弦相似度权重 |

**影响**:
- 向量检索占绝对主导（95%）
- 全文检索用于补充精确匹配

### 降级重试参数

**文件位置**: `rag/nlp/search.py:265-269`

| 参数 | 原始值 | 降级值 | 说明 |
|------|--------|--------|------|
| `min_match` | 0.6 | 0.1 | 全文检索最小匹配比例 |
| `similarity` | 用户指定 | 0.17 | 向量相似度阈值 |

## 重排序参数

### 内部混合相似度权重

**文件位置**: `rag/nlp/search.py:633`

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `tkweight` | 0.7 | 词元相似度权重 |

## 参数调优建议

### 1. 相似度阈值

| 场景 | 推荐值 | 说明 |
|------|--------|------|
| 高精度 | 0.3-0.5 | 减少召回，提高准确率 |
| 平衡 | 0.2 | 默认值 |
| 高召回 | 0.1-0.15 | 增加召回，可能降低准确率 |

### 2. 向量相似度权重

| 场景 | vector_weight | 说明 |
|------|---------------|------|
| 语义检索 | 0.9-0.95 | 强调语义相似度 |
| 平衡 | 0.7-0.8 | 默认值 |
| 关键词检索 | 0.3-0.5 | 强调精确匹配 |

### 3. Top-K

| 场景 | 推荐值 | 说明 |
|------|--------|------|
| 快速检索 | 100-300 | 减少计算量 |
| 平衡 | 500-800 | 默认值 |
| 高质量 | 1024 | 增加候选数量 |

### 4. Rerank 限制

| 场景 | page_size | 说明 |
|------|----------|------|
| 快速响应 | 10-20 | 减少重排序负担 |
| 平衡 | 30 | 默认值 |
| 高质量 | 50-100 | 更多候选结果 |

## 参数影响分析

### 检索质量 vs 性能

| 参数 | 提高质量 | 提高性能 |
|------|---------|---------|
| `similarity_threshold` | ↓ 降低阈值 | ↑ 提高阈值 |
| `top` | ↑ 增加值 | ↓ 减少值 |
| `page_size` | ↑ 增加值 | ↓ 减少值 |
| `vector_weight` | 根据场景 | 根据场景 |
| Rerank 模型 | ↑ 使用模型 | ↓ 不使用模型 |

### 内存使用

| 参数 | 内存影响 |
|------|---------|
| `top` | 线性增长 |
| `page_size` | 线性增长 |
| 嵌入维度 | 线性增长 |
| 批量大小 | 线性增长 |
