# 高级检索策略

> **核心文件**: `rag/nlp/search.py`
> **核心方法**: `Dealer.insert_citations()`, `Dealer.retrieval_by_toc()`, `Dealer.retrieval_by_children()`
> **相关文档**: [001-核心检索链路](./001-核心检索链路.md)

## 概述

RAGFlow 除了基础的混合检索外，还提供了多种高级检索策略：

1. **引文插入**: 自动为回答添加引用标记
2. **TOC 目录检索**: 基于文档目录结构的精准检索
3. **父子块检索**: 利用文档层级结构提升召回质量

本文档详细解析这些高级检索策略的实现。

#### 关键代码片段

##### 1. 句子分割

```python
# search.py:323-350
def _split_sentences(self, answer):
    """分割回答为句子列表"""
    sentences = []
    current = ""
    in_code_block = False

    for char in answer:
        if char == "`" and current.endswith("```"):
            in_code_block = not in_code_block
            current = current[:-3]
            continue

        if in_code_block:
            current += char
            continue

        current += char

        # 分割标点
        if char in ['。', '？', '!', '！', '\n']:
            sentences.append(current.strip())
            current = ""
        elif char in ['.', '?', '!', '\n']:
            # 英文标点（简单处理）
            if current and current[-1] == char:
                sentences.append(current.strip())
                current = ""

    if current:
        sentences.append(current.strip())

    return sentences
```

##### 2. 过滤短句

```python
# search.py:353-357
pieces_ = []
for p in pieces:
    if len(p) >= 5:  # 过滤长度 < 5 的句子
        pieces_.append(p)
```

##### 3. 计算相似度

```python
# search.py:359-390
# 句子向量化
sent_vecs, _ = embd_mdl.encode(pieces_)

# 计算句子-文档块相似度
sim, _, _ = self.qryr.hybrid_similarity(
    sent_vecs,    # 句子向量
    chunk_v,      # chunk 向量
    [],           # 查询词元（空）
    [],           # chunk 词元（空）
    0.0,          # 词元权重
    1.0           # 向量权重
)

# 为每个句子选择最相关的 chunk
cites = {}
for i, sent_sim in enumerate(sim):
    mx = max(sent_sim) * 0.99  # 动态阈值
    chunk_ids = [
        chunk_idx
        for chunk_idx, s in enumerate(sent_sim)
        if s > mx
    ]
    cites[i] = chunk_ids[:4]  # 最多引用 4 个
```

##### 4. 插入引文标记

```python
# search.py:392-407
def _insert_citation_marks(self, pieces, cites):
    """插入引文标记"""
    result = []
    chunk_ids = [c["chunk_id"] for c in chunks]

    for i, piece in enumerate(pieces):
        if i in cites and cites[i]:
            # 生成引文标记
            marks = " ".join([f"[ID:{chunk_ids[idx]}]" for idx in cites[i]])
            result.append(f"{piece} {marks}")
        else:
            result.append(piece)

    return " ".join(result)
```

它支持多种文档格式，包括 PDF、Word、Markdown 等。 [ID:chunk_002]
```

# search.py:922-940
async def relevant_chunks_with_toc(query, toc, chat_mdl):
    """使用 LLM 选择与查询相关的 TOC 章节"""

    prompt = f"""
请根据以下目录（TOC），选择与查询最相关的章节：

查询：{query}

目录：
{format_toc(toc)}

请返回相关章节的 ID 列表，最多 {topn} 个。
"""

    response = await chat_mdl.generate(prompt)

    # 解析 LLM 返回的章节 ID
    relevant_ids = parse_toc_ids(response)

    return relevant_ids
```

#### 关键代码片段

##### 1. 按母块 ID 分组

```python
# search.py:977-983
# 按母块 ID 分组子块
children_by_mom = {}
for chunk in chunks:
    mom_id = chunk.get("mom_id")
    if mom_id:
        if mom_id not in children_by_mom:
            children_by_mom[mom_id] = []
        children_by_mom[mom_id].append(chunk)
```

##### 2. 获取母块内容

```python
# search.py:985-1000
moms = []
for mom_id, children in children_by_mom.items():
    # 从存储层获取母块
    mom_chunks = dataStore.get(
        [mom_id],
        fields=["chunk_id", "content_with_weight", "doc_id", "kb_id"]
    )

    if mom_chunks:
        moms.append(mom_chunks[0])
```

##### 3. 计算母块相似度

```python
# search.py:1002-1010
for mom in moms:
    mom_id = mom["chunk_id"]
    children = children_by_mom[mom_id]

    # 母块相似度 = 子块相似度均值
    mom_sim = sum(c.get("similarity", 0) for c in children) / len(children)

    mom["similarity"] = mom_sim
```

##### 4. 合并结果

```python
# search.py:1012-1027
# 移除子块
filtered_chunks = [c for c in chunks if not c.get("mom_id")]

# 添加母块
filtered_chunks.extend(moms)

# 重新排序
filtered_chunks.sort(key=lambda x: x.get("similarity", 0), reverse=True)

return filtered_chunks
```

## 高级策略对比

| 策略 | 适用场景 | 优势 | 成本 |
|------|---------|------|------|
| 引文插入 | 知识问答 | 提升可信度、方便溯源 | 中 |
| TOC 检索 | 结构化文档 | 精准定位章节 | 高（需要 LLM） |
| 父子块检索 | 长文档 | 提供完整上下文 | 低 |

---

## 使用建议

### 1. 引文插入

- **适用**: 所有需要引用来源的场景
- **建议**: 开启 highlight 以获得更好的用户体验

### 2. TOC 检索

- **适用**: 有清晰目录结构的文档（如技术手册、论文）
- **建议**: 确保文档索引时包含 TOC 字段

### 3. 父子块检索

- **适用**: 长文档、需要完整上下文的场景
- **建议**: 配合合理的 chunk 划分策略使用
