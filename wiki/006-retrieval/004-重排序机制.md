# 重排序机制

> **核心文件**: `rag/nlp/search.py`
> **核心方法**: `Dealer.rerank()`, `Dealer.rerank_by_model()`
> **相关文档**: [001-核心检索链路](./001-核心检索链路.md), [002-全文查询构建](./002-全文查询构建.md)

---

## 概述

重排序是提升检索质量的关键环节。RAGFlow 支持两种重排序策略：

1. **内部混合相似度重排序**: 结合向量相似度和词元相似度
2. **外部 Rerank 模型重排序**: 使用专门的 Rerank 模型

本文档详细解析这两种重排序机制的实现。

> 修订说明（2026-04-26）：本文中 `token_similarity` 与 `_rank_feature_scores` 的部分示例为历史实现，已补充代码对齐说明。

## 重排序路由

**文件位置**: `rag/nlp/search.py:615-639`

### 路由逻辑

```
retrieval() 重排序路由
    │
    ├─ 有 rerank_mdl
    │   └─→ rerank_by_model()
    │       ├─ 使用外部 Rerank 模型
    │       ├─ 词元相似度 + 模型相似度
    │       └─ 加权混合
    │
    ├─ DOC_ENGINE == "infinity"
    │   └─→ 直接使用 _score
    │       └─ Infinity 已内置归一化
    │
    └─ 其他 (ES 引擎)
        └─→ rerank()
            ├─ 混合相似度重排序
            ├─ 词元相似度 + 向量相似度
            └─ 加权混合
```

```python

    │         )
    │
    ├─→ 【排序特征增强】 :485-486
    │     └─ rank_fea = self._rank_feature_scores(rank_feature, sres)

#### 词元增强权重

| 字段 | 增强倍数 | 说明 |
|------|----------|------|
| `content_ltks` | ×1 | 内容基础词元 |
| `title_tks` | ×2 | 标题词元加权 |
| `important_kwd` | ×5 | LLM 提取的关键词加权 |
| `question_tks` | ×6 | LLM 生成的问题加权 |

**说明**: 不同字段的词元在相似度计算中有不同的权重贡献。

#### 关键代码片段

#### 与内部重排序的区别

| 特性 | 内部重排序 | 模型重排序 |
|------|-----------|-----------|
| 词元增强 | 有（×2/×5/×6） | 无（同等权重） |
| 向量相似度 | cosine_similarity | Rerank 模型 |
| 计算成本 | 低 | 高 |
| 适用场景 | 快速检索 | 高质量检索 |

    self,
    avec,        # 查询向量
    bvecs,       # 文档向量列表
    atks,        # 查询词元
    btkss,       # 文档词元列表

```

#### 实现代码

```python
# query.py:276-309
def hybrid_similarity(self, avec, bvecs, atks, btkss, tkweight=0.3, vtweight=0.7):
    from sklearn.metrics.pairwise import cosine_similarity

    # 1. 向量相似度（余弦相似度）
    sims = cosine_similarity([avec], bvecs)[0]

    # 2. 词元相似度
    tksim = self.token_similarity(atks, btkss)

    # 3. 向量全零时降级为纯词元
    if np.sum(sims) == 0:
        return np.array(tksim), tksim, sims

    # 4. 加权混合
    hybrid_sim = vtweight * sims + tkweight * tksim

    return hybrid_sim, tksim, sims
```

#### 混合公式

```
hybrid_similarity = 0.7 * cosine_similarity + 0.3 * token_similarity
```

**说明**: 向量相似度占主导（70%），词元相似度补充精确匹配（30%）。

## 词元相似度计算

**文件位置**: `rag/nlp/query.py:311-352`

### token_similarity() 方法详解

> 代码对齐说明：当前代码中的 `token_similarity()` 并非此处展示的 Jaccard+位置函数实现，
> 而是基于 `term_weight` 的加权词典（含相邻 bigram）后计算相似度。

#### 方法签名

```python
def token_similarity(self, atks, btkss):
    """
    计算词元相似度

    Args:
        atks: 查询词元列表
        btkss: 文档词元列表列表

    Returns:
        list: 相似度分数列表
    """
```

#### 实现代码

```python
# query.py:311-352
def token_similarity(self, atks, btkss):
    if not atks or not btkss:
        return [0.0] * len(btkss)

    atks_set = set(atks)
    scores = []

    for btk in btkss:
        if not btk:
            scores.append(0.0)
            continue

        btk_set = set(btk)

        # Jaccard 相似度
        intersection = atks_set & btk_set
        union = atks_set | btk_set
        jaccard = len(intersection) / len(union) if union else 0.0

        # 位置权重增强
        position_boost = self._position_weight(atks, btk)

        scores.append(jaccard * (1 + position_boost))

    return scores
```

#### Jaccard 相似度

```
Jaccard(A, B) = |A ∩ B| / |A ∪ B|
```

**说明**: 计算查询词元和文档词元的交集与并集比例。

#### 位置权重

```python
# query.py:345-352
def _position_weight(self, atks, btk):
    """计算位置权重（词在前面权重更高）"""
    boost = 0.0
    for i, tk in enumerate(atks):
        if tk in btk:
            pos = btk.index(tk)
            # 位置越靠前，权重越高
            boost += (len(btk) - pos) / len(btk)

    return boost / len(atks) if atks else 0.0
```

**说明**: 匹配词在文档中出现的位置越靠前，权重越高。

```python
# search.py:409-435
def _rank_feature_scores(self, rank_feature, sres):
    if not rank_feature:
        return np.zeros(len(sres.ids))

    scores = np.zeros(len(sres.ids))

    # PageRank 特征
    if PAGERANK_FLD in rank_feature:
        pagerank_weight = rank_feature[PAGERANK_FLD]
        for i, doc_id in enumerate(sres.ids):
            pagerank = sres.field[doc_id].get(PAGERANK_FLD, 0)
            scores[i] += pagerank * pagerank_weight

    # 标签特征
    if TAG_FLD in rank_feature:
        target_tag = rank_feature[TAG_FLD]
        tag_weight = rank_feature.get(f"{TAG_FLD}_weight", 1.0)
        for i, doc_id in enumerate(sres.ids):
            tags = sres.field[doc_id].get(TAG_FLD, [])
            if target_tag in tags:
                scores[i] += tag_weight

    return scores
```

#### 特征类型

| 特征 | 字段 | 说明 | 默认权重 |
|------|------|------|---------|
| PageRank | `pagerank_flt` | 文档重要性分数 | 10 |
| 标签 | `tag_kwd` | 文档标签 | 1.0 |

#### 特征配置示例

```python
rank_feature = {
    "pagerank_flt": 10,          # PageRank 权重
    "tag_kwd": "important",      # 目标标签
    "tag_kwd_weight": 5.0        # 标签匹配权重
}
```

## 重排序性能对比

| 策略 | 计算成本 | 检索质量 | 适用场景 |
|------|---------|---------|---------|
| 内部混合相似度 | 低 | 中 | 快速检索、实时响应 |
| 外部 Rerank 模型 | 高 | 高 | 高质量检索、离线处理 |
