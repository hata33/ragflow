## 路径 3: 混合检索

**文件位置**: `rag/nlp/search.py:252`

### 使用场景

- 有嵌入模型配置
- 需要结合语义和关键词匹配

### 实现代码

```python
# search.py:236-252
# 1. 构建全文查询
matchText, keywords = self.qryr.question(qst)

# 2. 向量化查询
matchDense = await self.get_vector(qst, emb_mdl, topk, similarity)

# 3. 构建融合策略
fusionExpr = FusionExpr("weighted_sum", topk, {"weights": "0.05,0.95"})

# 4. 执行混合检索
res = dataStore.search(
    src,
    hl,
    filters,
    [matchText, matchDense, fusionExpr],
    orderBy,
    req
)
```

### 融合策略详解

#### 表达式列表

| 表达式 | 类型 | 权重 | 说明 |
|--------|------|------|------|
| `matchText` | `MatchTextExpr` | 0.05 | 全文检索（BM25） |
| `matchDense` | `MatchDenseExpr` | 0.95 | 向量检索（cosine） |
| `fusionExpr` | `FusionExpr` | - | weighted_sum 融合策略 |

#### 融合公式

```
final_score = 0.05 * bm25_score + 0.95 * cosine_similarity
```

**说明**: 向量检索占绝对主导（95%），全文检索用于补充精确匹配。

## 降级重试机制

**文件位置**: `rag/nlp/search.py:258-269`

### 触发条件

```python
if total == 0:  # 首次检索无结果
```

### 重试策略

#### 策略 1: 指定文档范围

```python
# search.py:260-264
if filters.get("doc_id"):
    # 去掉匹配条件，只按过滤条件和排序检索
    res = dataStore.search(src, [], filters, [], orderBy, req)
```

**适用场景**: 用户明确指定了文档 ID，可能是文档内容刚索引还未完全生效。

#### 策略 2: 降低阈值

```python
# search.py:265-269
else:
    # 降低全文匹配门槛
    matchText, _ = self.qryr.question(qst, min_match=0.1)  # 原始 0.3

    # 降低向量相似度阈值
    matchDense.extra_options["similarity"] = 0.17

    # 重新检索
    res = dataStore.search(src, hl, filters, [matchText, matchDense, fusionExpr], orderBy, req)
```

**适用场景**: 查询过于严格导致无结果，通过降低阈值召回更多候选。

### 参数对比

| 参数 | 原始值 | 降级值 | 说明 |
|------|--------|--------|------|
| `min_match` | 0.3 | 0.1 | 全文检索最小匹配比例 |
| `similarity` | 用户指定 | 0.17 | 向量相似度阈值 |

### 标签匹配

```python
# search.py:271-293
def _rank_feature_scores(self, rank_feature, sres):
    """计算排序特征分数"""
    if not rank_feature:
        return np.zeros(len(sres.ids))

    scores = np.zeros(len(sres.ids))

    # PageRank 特征
    if PAGERANK_FLD in rank_feature:
        for i, doc_id in enumerate(sres.ids):
            pagerank = sres.field[doc_id].get(PAGERANK_FLD, 0)
            scores[i] += pagerank * rank_feature[PAGERANK_FLD]

    # 标签特征
    if TAG_FLD in rank_feature:
        for i, doc_id in enumerate(sres.ids):
            tags = sres.field[doc_id].get(TAG_FLD, [])
            if rank_feature[TAG_FLD] in tags:
                scores[i] += rank_feature[f"{TAG_FLD}_weight"]

    return scores
```

## 检索结果结构

### SearchResult 数据类

```python
@dataclass
class SearchResult:
    total: int                          # 总结果数
    ids: list[str]                      # chunk ID 列表
    query_vector: list[float]           # 查询向量
    field: dict                         # {chunk_id: {field: value}}
    highlight: dict                     # {chunk_id: highlighted_text}
    aggregation: list                   # 聚合结果
    keywords: list[str]                 # 提取的关键词
    scores: list[float]                 # 相似度分数（可选）
```
