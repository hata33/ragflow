# RAGFlow 项目概述

## 项目简介

RAGFlow 是一个基于深度文档理解的开源 RAG（Retrieval-Augmented Generation）引擎。它结合了先进的文档解析能力、强大的检索系统和灵活的 LLM 集成，为企业级知识管理和智能问答提供完整解决方案。

## 核心特性

### 1. 深度文档理解
- 支持多种文档格式：PDF、DOCX、Excel、HTML、Markdown、TXT 等
- 智能版面分析和 OCR 识别
- 保留文档结构和格式信息
- 支持表格、图表等复杂内容提取

### 2. 灵活的 RAG 管道
- 多种文本分块策略
- 可配置的向量化和检索参数
- 混合检索（向量 + 关键词）
- 智能重排序优化结果

### 3. Agent 工作流
- 可视化画布编排
- 丰富的组件库（LLM、检索、分类等）
- 支持循环和条件分支
- 预置常用模板

### 4. 多模型支持
- Chat 模型：OpenAI、Anthropic、通义千问、文心一言等
- Embedding 模型：多种向量化选择
- Rerank 模型：结果重排序优化
- OCR 模型：文档图像识别

### 5. 企业级功能
- 多租户支持
- 细粒度权限控制
- API 密钥管理
- 数据隔离和安全

## 核心流程

### 文档处理流程
```
文档上传 → 格式检测 → 内容解析 → 文本分块 → 向量化 → 存储索引
```

### RAG 问答流程
```
用户查询 → 检索相关文档 → 上下文组装 → LLM 生成 → 返回答案
```

### Agent 执行流程
```
画布定义 → 组件编排 → 执行引擎 → 结果输出
```

## 开发指南

### 环境要求
- Python 3.10-3.12
- Node.js >= 18.20.4
- Docker & Docker Compose
- 16GB+ RAM
- 50GB+ 磁盘空间

### 快速开始

1. **克隆项目**
```bash
git clone https://github.com/infiniflow/ragflow.git
cd ragflow
```

2. **启动依赖服务**
```bash
docker compose -f docker/docker-compose-base.yml up -d
```

3. **启动后端**
```bash
uv sync --python 3.12 --all-extras
source .venv/bin/activate
bash docker/launch_backend_service.sh
```

4. **启动前端**
```bash
cd web
npm install
npm run dev
```
